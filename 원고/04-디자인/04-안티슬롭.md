AI에게 화면을 맡기면 못생기지는 않았는데 어디서 본 것 같고, 기억에 남지 않습니다. 이것을 슬롭(slop)이라고 부르는데, 핵심은 **못생긴 게 아니라 선택이 아닌 것**이라는 점입니다 — 2절이 내 손의 티를 지웠다면 이 절은 AI의 지문을 지웁니다.

## ① 지문 다섯을 알아본다

AI가 화면을 만들 때 거의 항상 나오는 다섯입니다. 하나만 있어도 눈치챕니다.

| 지문 | 고치는 법 |
|---|---|
| 파랑→보라 그라디언트 | 그라디언트를 아예 금지합니다. 색은 한 가지로 단단하게 |
| 같은 영문 기본 글꼴 도배 | 글꼴을 내가 고른 것으로 지정합니다. 한글이면 Pretendard가 무난한 출발점 |
| 아이콘 + 제목 + 두 줄 설명 카드 세 개 | 개수를 바꾸거나(둘·다섯) 세로 목록으로. 아이콘 대신 숫자나 실제 화면 |
| 유리 질감(반투명·흐림) | 반투명·흐림 효과를 금지합니다. 배경은 단색, 경계는 선 하나 |
| 가운데 정렬 히어로 | 왼쪽 정렬로 바꿉니다. 그것만으로 인상이 달라지고 읽기도 쉽습니다 |

글꼴은 여전히 하나지만, **"AI가 고른 하나"와 "내가 고른 하나"는 다릅니다.**

## ② 말로 되는 것과 안 되는 것을 가른다

여기가 이 절에서 가장 중요한 부분입니다. 말로 다 되는 게 아닙니다.

| 프롬프트로 되는 것 | 프롬프트로 안 되는 것 |
|---|---|
| 정확한 색상값 — `#0057FF`처럼 숫자로 | "세련되게" "고급스럽게" — 평균값으로 돌아갑니다 |
| 글꼴 이름 | "우리 브랜드 느낌으로" — 브랜드가 뭔지 AI가 모릅니다 |
| 금지 목록 — "그라디언트 금지" | "흔하지 않게" — 흔한 게 뭔지 판단 기준이 없습니다 |
| 숫자 규칙 — 간격·대비·단계 수 | 색감·질감·여백의 밀도 — 형용사로 안 잡힙니다 |
| 개수 지정 — "카드는 다섯 개" | 전체 인상 — 5절 「그림으로 보여주기」로 갑니다 |

**측정되는 것은 말로, 측정 안 되는 것은 그림으로.** 말로 세 번 고쳐도 안 잡히면 프롬프트 문제가 아니니 5절로 갑니다.

## ③ 한 군데만 튀게 정한다

전부 특별하게 만들면 오히려 어수선해집니다. **한 군데만** 정하세요.

- 아주 큰 숫자 하나
- 아주 긴 제목 하나 (남들이 짧게 쓰는 자리에)
- 색을 딱 한 곳에만 (나머지는 전부 무채색)
- 사진이 아니라 손으로 그린 선 하나

나머지 아홉은 규칙대로, 하나만 의도적으로. 혼자 만드는 사람이 쓸 수 있는 가장 값싼 차별화입니다.

## ⚡ 따라 하기

1. 3절 규칙표의 「하지 말 것」에 아래 다섯 줄을 넣으세요. 대화창에 쓰면 새 대화에서 사라지기 때문입니다. 지침 파일에 금지 줄이 여덟 개가 되면 됩니다.

```
[하지 말 것 — AI 티 나는 다섯]
- 그라디언트를 쓰지 않는다. 특히 파랑→보라
- 글꼴은 규칙표에 적힌 것 하나만 쓴다
- 아이콘 + 제목 + 두 줄 설명 카드를 가로로 셋 놓지 않는다
- 반투명·흐림(유리 질감) 효과를 쓰지 않는다
- 첫 화면을 가운데 정렬로 만들지 않는다. 왼쪽 정렬을 기본으로 한다
```

2. AI가 만든 화면을 하나 열고 다섯 개가 있는지 **하나씩 세어** 보세요. 이름을 알면 눈에 보이는지 확인하는 연습입니다. "있음/없음" 다섯 줄이 나오면 됩니다.
3. 아래를 붙여넣어 검사시키세요. 있는 것만 고치고, 튀어야 할 자리 하나까지 받기 위해서입니다. 마지막 줄에 제안 하나가 오면 됩니다.

```
이 화면에서 아래 다섯 가지가 있는지 하나씩 확인해줘. 있으면 "있음 + 어디에", 없으면 "없음"으로만 답해줘.
1. 그라디언트 (특히 파랑에서 보라)
2. 규칙표에 없는 글꼴
3. 아이콘 + 제목 + 두 줄 설명 카드가 가로로 세 개
4. 반투명·흐림 효과
5. 가운데 정렬 히어로

그다음, 있는 것만 아래 규칙으로 고쳐줘.
- 색은 규칙표의 값만 쓴다
- 첫 화면은 왼쪽 정렬로 바꾼다
- 카드는 세 개 배치를 쓰지 않는다
마지막에 "이 화면에서 유일하게 튀어야 할 것 하나"를 골라 제안해줘.
```

## ✅ 확인

- [ ] AI 지문 다섯을 이름으로 말할 수 있나
- [ ] 금지 목록이 대화창이 아니라 규칙표 파일에 들어갔나
- [ ] 내 화면에 그라디언트가 하나도 없고, 첫 화면이 왼쪽 정렬인가 (가운데를 일부러 골랐다면 그것도 «예»)
- [ ] "여기 하나만 튄다"고 지목할 수 있는 자리가 있나

## 📘 말 풀이

**슬롭(slop)** — AI가 대량으로 뽑아낸, 평균적이고 특징 없는 결과물. "아무 선택도 하지 않은" 상태입니다.

**그라디언트(gradient)** — 한 색에서 다른 색으로 서서히 흐르게 칠하는 것. 파랑→보라가 AI 결과물의 대표 표식입니다.

**히어로(hero)** — 웹페이지 맨 위, 열자마자 보이는 가장 큰 영역. 제목과 버튼이 들어가는 자리입니다.

## ⚠️ 함정

**"AI 티를 없애 줘"라고만 말합니다.** AI는 자기 지문을 모릅니다. 다섯 개를 이름으로 지목해야 지웁니다.

**전부 특이하게 만들려 합니다.** 그러면 2절의 다섯 가지 문제가 다시 돌아옵니다. 규칙이 먼저, 일탈은 한 곳만.

**"무난해도 깔끔하니까 됐다"고 넘어갑니다.** 깔끔함은 통과 기준이지 목표가 아닙니다.

**AI에게 "창의적으로"라고 요구합니다.** 이 말은 평균값을 부르는 말입니다. 구체적인 제약이 창의를 만듭니다.
