비개발자가 AI 코딩을 포기하는 첫 번째 이유는 실력이 아니라 **검은 화면**입니다. 지금은 데스크톱 앱이 있어서 창을 열고 한국어로 말하면 됩니다.

## ① 앱 하나로 하루를 돌린다

파일을 붙이는 것도, 중단하는 것도, 권한을 조절하는 것도 앱 안에서 됩니다.

| 무엇을 | 어디서 | 얼마나 |
|---|---|---|
| 계획·만들기·고치기 | 데스크톱 앱 | 하루의 90% |
| 커밋·되돌리기 | 앱 안에서 말로 ([[045-버전관리/_스테이지|Stage 4.5]]) | 나머지 |
| 두 번째 눈으로 리뷰 | 다른 도구 하나 ([[07-배포PR/_스테이지|Stage 7]]) | 밀기 직전 한 번 |

**도구는 둘이면 됩니다 — 메인 하나, 백업 하나.** 백업은 메인이 멈췄을 때만 켭니다. 셋 이상 깔면 배우는 시간만 늘고 안전은 나빠집니다.

## ② @와 !로 대화에 붙인다

입력창에 `@`를 치면 폴더 안 파일 목록이 뜹니다. 골라서 넣으면 그 파일이 대화로 들어갑니다 — 복사하면 줄이 잘리거나 일부만 들어가서, `@`가 더 정확합니다.

```
@src/subscribe.tsx 이 화면에서 이메일 형식이 틀렸을 때 어떻게 되는지 알려 줘
```

`!`로 시작하면 그 뒤의 명령을 실행해서 결과만 대화에 넣습니다. 에러가 났을 때 특히 중요합니다 — **에러는 요약하지 말고 그대로 넣습니다** ([[05-구현/5-막혔을때|5절]]).

```
!npm test
```

## ③ Esc로 멈춘다

AI가 엉뚱한 방향으로 달리면 `Esc` 한 번으로 즉시 멈춥니다. 잘 안 멈추면 `Ctrl` + `C`가 비상 정지입니다.

멈추는 게 미안한 일이 아닙니다. **끝까지 가게 두는 게 더 비쌉니다.**

## ④ 자동 수락을 가른다

자동 수락은 "하나하나 물어보지 말고 알아서 해"라는 스위치입니다. 켜면 빠르고, 켜 둔 채 잘못된 일을 시키면 아주 빠르게 망합니다.

> **되돌릴 수 있으면 켠다. 밖으로 나가면 끈다.**

| 하는 일 | 되돌릴 수 있나 | 자동 수락 |
|---|---|---|
| 내 컴퓨터 안 파일 고치기(커밋해 뒀다면) · 문구 다듬기 · 테스트 돌리기 | ⭕ | 켠다 |
| 새 도구·부품 설치 | 🔺 지저분해짐 | 꺼 둔다 |
| 데이터 지우기 · 실제 메일·문자 발송 · 결제·환불 | ❌ | 끈다 |
| 배포 · 저장소에 밀기 · 남의 서비스에 닿는 일 | ❌ 남 눈에 보임 | 끈다 |

켜기 전 조건이 하나 더 있습니다 — 지금 상태가 커밋되어 있어야 합니다. 커밋이 없으면 안전망 없는 외줄타기입니다.

## ⚡ 따라 하기

1. 프로젝트 폴더에서 앱을 열고 아래를 붙이세요 — 지침 파일과 커밋 상태를 알아야 안전하게 시작합니다. 지침 요약 세 줄과 "커밋 안 된 변경이 있다/없다"가 돌아와야 합니다.

```
지금 이 폴더에서 시작할게.
1. 이 폴더에 CLAUDE.md 같은 지침 파일이 있나? 있으면 무슨 내용인지 세 줄로
2. 지금 커밋 안 된 변경이 있나?
3. 아직 아무것도 고치지 마. 위 두 가지만 알려 줘.
```

2. `@`를 쳐서 파일 하나를 고르고 아래를 붙이세요 — 복사·붙여넣기 없이 파일을 넘기는 감각을 익히기 위해서입니다. 다섯 줄 설명이 돌아오면 붙은 것입니다.

```
@(파일 경로를 @로 골라서 넣습니다)

이 파일이 무슨 일을 하는지 비개발자가 알아듣게 다섯 줄로 설명해 줘.
이 파일에서 잘못되면 사용자가 바로 알아채는 부분이 어디인지도 알려 줘.
```

3. 커밋을 한 뒤 아래를 붙이고 자동 수락을 켜세요 — 밖으로 나가는 일만 물어보게 선을 긋기 위해서입니다. 이후 파일 고치기는 묻지 않고 진행되고, 목록에 든 일은 멈춰서 물어봐야 합니다.

```
지금부터 하려는 일 중에 아래에 해당하는 게 있으면 먼저 나에게 물어봐.
- 데이터를 지우거나 덮어쓴다
- 메일·문자·알림을 실제로 밖으로 보낸다
- 결제나 돈에 관련된 것을 건드린다
- 인터넷에 올리거나 저장소에 밀어 올린다
- .env 같은 비밀 값이 든 파일을 읽거나 고친다

나머지(내 컴퓨터 안 파일 고치기, 테스트 돌리기)는 물어보지 말고 진행해도 돼.
```

4. AI가 엉뚱하게 달리면 `Esc`를 누르고 아래를 붙이세요 — 더 망가지기 전에 무엇이 바뀌었는지 알아야 합니다. 바뀐 파일 목록만 돌아오고, 되돌리기는 내가 시킬 때까지 하지 않아야 합니다.

```
멈춰. 지금까지 바꾼 파일 목록만 보여 줘. 더 고치지 마.
되돌려야 할 것이 있으면 알려 줘. 되돌리기는 내가 시킬 때만 해.
```

## ✅ 확인

- [ ] 검은 화면을 열지 않고 앱 안에서만 한 바퀴를 돌았나
- [ ] `@`로 파일을, `!`로 명령 결과를 붙여 봤나
- [ ] `Esc`로 AI를 한 번 멈춰 봤나
- [ ] 자동 수락을 켜기 전에 커밋을 했나

## 📘 말 풀이

**터미널(terminal)** — 글자만 입력해서 컴퓨터에 명령하는 검은 화면. 지금은 앱 안에서 `!`로 대신할 수 있습니다.

**자동 수락** — AI가 하려는 일을 하나하나 묻지 않고 진행하게 하는 스위치. 되돌릴 수 있는 일에만 켭니다.

**배포** — 내 컴퓨터 안에서만 돌던 것을 인터넷에 올려 남이 보게 하는 일. 밖으로 나가는 일이라 자동 수락을 끕니다.

## ⚠️ 함정

**"전부 자동" 같은 가장 센 설정을 첫날 켭니다.** 첫 며칠은 하나하나 물어보는 상태로 씁니다. 무엇을 승인하는지 배우는 시간입니다.

**`.env` 파일을 `@`로 붙입니다.** 비밀번호·열쇠가 든 파일입니다. 값이 필요하면 "열쇠 이름만 넣어 둬"라고 말합니다.

**밖으로 나가는 일을 켜 둔 채 자리를 뜹니다.** 실제 사고입니다 — "운영 데이터 건드리지 마"를 지침 파일에만 적고 막는 장치가 없던 경우, 에이전트가 운영 데이터베이스를 지웠습니다. 말로 적은 규칙은 100%가 아니므로, 절대 안 되는 것은 자동 수락을 끄는 것으로 막습니다.
