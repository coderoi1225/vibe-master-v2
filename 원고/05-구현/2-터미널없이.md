비개발자가 AI 코딩을 포기하는 첫 번째 이유는 실력이 아닙니다.
**검은 화면**입니다.

## 왜 이걸 하나

"AI로 개발한다"는 말을 들으면 대부분 글자만 가득한 검은 화면을 떠올립니다.
그리고 첫날 그 화면을 보고 조용히 닫습니다.

그런데 지금은 **데스크톱 앱**이 있습니다. 창을 열고 한국어로 말하면 됩니다.
파일을 붙이는 것도, 중단하는 것도, 권한을 조절하는 것도 전부 앱 안에서 됩니다.

이 절을 건너뛰면 두 가지가 생깁니다.
첫째, 매번 "어떻게 파일을 보여주지?" 하며 내용을 복사·붙여넣기 하다가 지칩니다.
둘째, **자동 수락을 잘못 켜 두고** 밖으로 나가는 일까지 AI에게 맡깁니다. 그건 사고입니다.

## 하루의 90%는 앱 하나에서 끝난다

| 무엇을 | 어디서 | 얼마나 |
|---|---|---|
| 계획 세우기·만들기·고치기 | **데스크톱 앱** | 하루의 90% |
| 커밋·되돌리기 | 앱 안에서 말로 (Stage 4.5) | 나머지 |
| 두 번째 눈으로 리뷰 | 다른 도구 하나 (Stage 7) | 밀기 직전 한 번 |

**도구는 둘이면 됩니다. 메인 하나, 백업 하나.**
메인은 앱으로 쓰고, 백업은 메인이 멈췄을 때만 켭니다.
셋 이상 깔면 배우는 시간만 늘고 안전은 오히려 나빠집니다.

## 앱에서 손에 익힐 것 넷

### ① `@` — 파일을 대화에 붙인다

입력창에 **`@`** 를 치면 폴더 안 파일 목록이 뜹니다. 골라서 넣으면 그 파일이 대화로 들어갑니다.

```
@src/subscribe.tsx 이 화면에서 이메일 형식이 틀렸을 때 어떻게 되는지 알려 줘
```

내용을 복사해서 붙일 필요가 없습니다. **`@`가 훨씬 정확합니다** — 복사하면 줄이 잘리거나 일부만 들어갑니다.
폴더도 붙일 수 있습니다. 다만 폴더를 통째로 붙이면 그릇이 금방 찹니다. **필요한 파일만.**

### ② `!` — 명령 결과를 대화에 붙인다

입력창에서 **`!`** 로 시작하면 그 뒤의 명령을 실행해서 **결과만** 대화에 넣습니다.
검은 화면을 따로 열 필요가 없다는 뜻입니다.

```
!npm test
```

에러가 났을 때 이게 특히 중요합니다. 절 5에서 다시 나옵니다 — **에러는 요약하지 말고 그대로 넣습니다.**

### ③ 중단 — `Esc`

AI가 엉뚱한 방향으로 달리기 시작하면 **`Esc`** 한 번으로 즉시 멈춥니다.
멈추는 게 미안한 일이 아닙니다. **끝까지 가게 두는 게 더 비쌉니다.**
잘 안 멈추면 `Ctrl` + `C`가 비상 정지입니다.

멈춘 다음에는 이렇게 말합니다.

```
지금 하던 것 멈추고, 방금까지 무엇을 바꿨는지만 알려 줘. 더 고치지 마.
```

### ④ 자동 수락 — 켜고 끄기

**자동 수락**은 "하나하나 물어보지 말고 알아서 해"라는 스위치입니다.
켜면 빠릅니다. 그리고 켜 둔 채로 잘못된 일을 시키면 **아주 빠르게 망합니다.**

기본은 **꺼 둡니다.** 그리고 아래 기준으로만 켭니다.

## ⭐ 언제 켜고 언제 끄나 — 기준은 하나

> **되돌릴 수 있으면 켠다. 밖으로 나가면 끈다.**

| 하는 일 | 되돌릴 수 있나 | 자동 수락 |
|---|---|---|
| 내 컴퓨터 안 파일 고치기 (커밋해 뒀다면) | ⭕ | **켠다** |
| 화면 모양·문구 다듬기 | ⭕ | **켠다** |
| 테스트 돌리기 | ⭕ | **켠다** |
| 새 도구·부품 설치하기 | 🔺 되돌릴 수 있지만 지저분해짐 | 꺼 둔다 |
| 데이터베이스 내용 지우기 | ❌ | **끈다** |
| 실제로 메일·문자 보내기 | ❌ 이미 받은 사람에게서 못 뺏음 | **끈다** |
| 결제·환불 건드리기 | ❌ | **끈다** |
| 인터넷에 올리기(배포)·저장소에 밀기 | 🔺 되돌리기가 남 눈에 보임 | **끈다** |
| 남의 컴퓨터·남의 서비스에 닿는 일 | ❌ | **끈다** |

**자동 수락을 켜기 전 조건이 하나 더 있습니다 — 지금 상태가 커밋되어 있어야 합니다.**
Stage 4.5에서 만든 저장소가 여기서 안전벨트가 됩니다. 커밋이 없으면 자동 수락은 안전망 없는 외줄타기입니다.

## ⚠️ 자주 걸리는 함정

- **"전부 자동" 같은 가장 센 설정을 첫날 켠다** — 첫 며칠은 하나하나 물어보는 상태로 씁니다. 무엇을 승인하는지 배우는 시간입니다.
- **커밋 안 한 상태에서 자동 수락을 켠다** — 되돌릴 데가 없습니다. 켜기 전에 커밋.
- **`.env` 파일을 `@`로 붙인다** — 비밀번호·열쇠가 들어 있는 파일입니다. 대화에 붙이지 않습니다. 값이 필요하면 "여기에 열쇠 이름만 넣어 둬"라고 말합니다.
- **폴더를 통째로 붙인다** — 그릇이 금방 차서 답이 나빠집니다. 파일 단위로.
- **밖으로 나가는 일을 켜 둔 채 자리를 뜬다** — 실제로 있었던 사고입니다. "운영 데이터 건드리지 마"라고 **지침 파일에만 적어 두고** 실행을 막는 장치는 없었던 경우, 에이전트가 운영 데이터베이스를 지웠습니다. **말로 적은 규칙은 대체로 지켜지지만 100%는 아닙니다.** 절대 안 되는 것은 자동 수락을 끄는 것으로 막습니다.

## 📘 말 풀이

- **터미널** — 글자만 입력해서 컴퓨터에 명령하는 검은 화면. 지금은 대부분 앱 안에서 `!`로 대신할 수 있어서, 비개발자는 따로 배우지 않아도 됩니다.
- **자동 수락** — AI가 하려는 일을 하나하나 묻지 않고 알아서 진행하게 하는 스위치. **되돌릴 수 있는 일에만** 켭니다.
- **배포** — 내 컴퓨터 안에서만 돌던 것을 인터넷에 올려서 남이 볼 수 있게 하는 일. 밖으로 나가는 일이므로 자동 수락을 끕니다. 본격적인 것은 Stage 7입니다.

## ⚡ 이렇게 하세요

**① 앱에서 첫 대화 — 지금 무엇을 쓸 수 있는지 확인**

```
지금 이 폴더에서 시작할게.
1. 이 폴더에 CLAUDE.md 같은 지침 파일이 있나? 있으면 무슨 내용인지 세 줄로
2. 지금 커밋 안 된 변경이 있나?
3. 아직 아무것도 고치지 마. 위 두 가지만 알려 줘.
```

**② 파일을 붙여서 물어보기**

```
@(파일 경로를 @로 골라서 넣습니다)

이 파일이 무슨 일을 하는지 비개발자가 알아듣게 다섯 줄로 설명해 줘.
그리고 이 파일에서 잘못되면 사용자가 바로 알아채는 부분이 어디인지 알려 줘.
```

**③ 자동 수락을 켜기 전에 스스로에게 묻기 — 이 세 줄을 붙여 두세요**

```
지금부터 하려는 일 중에 아래에 해당하는 게 하나라도 있으면 먼저 나에게 물어봐.
- 데이터를 지우거나 덮어쓴다
- 메일·문자·알림을 실제로 밖으로 보낸다
- 결제나 돈에 관련된 것을 건드린다
- 인터넷에 올리거나 저장소에 밀어 올린다
- .env 같은 비밀 값이 든 파일을 읽거나 고친다

나머지(내 컴퓨터 안 파일 고치기, 테스트 돌리기)는 물어보지 말고 진행해도 돼.
```

**④ 잘못 달리고 있을 때 — Esc 누르고 이 한 줄**

```
멈춰. 지금까지 바꾼 파일 목록만 보여 줘. 더 고치지 마.
그중에서 되돌려야 할 것이 있으면 어떤 것인지 알려 줘. 되돌리기는 내가 시킬 때만 해.
```
