## 왜 이걸 하나

문의 응대는 1인 회사에서 가장 많이 반복되고, 가장 자주 밤에 옵니다.
"영업시간이 어떻게 되나요", "이거 어디서 신청하나요" 같은 질문에 하루 몇 번씩 답하다 보면 다른 일이 안 됩니다.

그래서 CS 봇은 켜는 게 맞습니다. **다만 이 섹션에서 가장 위험한 자동화이기도 합니다.**

> ⭐ **회사는 자기 채널에서 챗봇이 말한 가격·정책에 «법적 책임»을 집니다.**

이 절은 봇을 켜지 말라는 절이 아니라, **켜되 회사가 다치지 않는 모양으로 켜는** 절입니다.
설계가 반이고, 설계는 아래 흐름도 한 장이면 끝납니다.

> 이 절의 법 이야기는 **법률 자문이 아닙니다.** 실제 분쟁이나 계약 문제는 변호사에게 확인합니다.

## 흐름 — 이 모양을 벗어나지 않습니다

```
FAQ·약관·가격표 문서
  → 근거가 있을 때만 답변
  → 근거 없음 / 확신 낮음 / 환불·가격·계약 키워드 → 즉시 사람에게
  → 대화 전문 + 근거 문서를 함께 넘김
```

네 줄을 풀면 이렇습니다.

**1) 근거는 문서에서만 온다.**
봇이 참고할 문서를 내가 정해 줍니다. FAQ, 약관, 가격표. 그 밖의 지식으로 답하지 않게 합니다.

**2) 근거가 있을 때만 답한다.**
문서에서 답을 못 찾으면 «지어내는 것»이 아니라 «모른다고 말하는 것»이 정답입니다.

**3) 세 가지 조건 중 하나라도 걸리면 즉시 사람에게.**
근거를 못 찾았거나, 찾긴 했는데 애매하거나, **환불·가격·계약 같은 말이 나왔거나.**
셋째가 특히 중요합니다. 근거가 있어 보여도 이 단어가 나오면 넘깁니다.

**4) 넘길 때 대화 전문과 근거 문서를 같이 넘긴다.**
사람이 이어받았을 때 "무슨 얘기였죠?"부터 다시 시작하면 고객은 두 번 설명해야 합니다.
넘기는 것은 사람이 아니라 **맥락**입니다.

## ⭐ 왜 이렇게까지 하나 — 실제로 벌어진 일

**항공사 챗봇 사건 (2024)**

항공사 챗봇이 **실제로는 존재하지 않는 할인 정책**을 만들어 고객에게 안내했습니다.
고객은 그 안내를 믿고 결정했고, 나중에 그런 정책이 없다는 걸 알게 됐습니다.

회사는 이렇게 주장했습니다.

> *"챗봇은 별개의 법인이다."*

심판부는 이 주장을 **배척**했습니다. 판단은 이랬습니다.

> *"챗봇은 웹사이트의 일부일 뿐이다. 정적 페이지든 챗봇이든 차이가 없다."*

그리고 **회사에 배상을 명령했습니다.**

**개발 도구 회사 사건 (2025)**

한 개발 도구 회사의 지원 봇이 **없는 정책**을 만들어 여러 사용자에게 퍼뜨렸습니다.
사용자들이 그 정책을 사실로 받아들이고 구독을 해지하는 일이 벌어졌고, 회사는 **공개 사과**했습니다.

**여기서 남는 한 줄**

> 봇이 한 말은 «봇이 한 말»이 아니라 **«회사가 한 말»**입니다.
> 웹사이트에 잘못 적어 놓은 가격에 책임을 지듯이, 봇이 잘못 말한 가격에도 책임을 집니다.

1인 법인 대표에게 이 말은 이렇게 번역됩니다 — **봇이 만든 약속을 내가 지켜야 합니다.**
그래서 봇에게 약속할 권한을 주지 않는 것이 유일한 방어입니다.

## 안전장치 여섯

| # | 무엇 | 어떻게 |
|---|---|---|
| ① | **모르면 모른다고** | "제가 확인할 수 없는 내용입니다. 담당자에게 연결해 드릴게요." 추측 금지 |
| ② | ⭐ **가격·환불·계약·기한은 확정 답변 금지** | 안내는 하되 «확정»하지 않습니다. "요금표는 여기 있습니다"는 되고, "고객님은 환불 대상입니다"는 안 됩니다 |
| ③ | **출처 표시** | 답변 끝에 "출처: 이용약관 ○조" 처럼. 근거 없는 답을 걸러 내는 데도 씁니다 |
| ④ | **항상 「사람과 대화하기」 버튼** | 대화 어느 단계에서도 사람에게 갈 수 있어야 합니다. 숨기면 안 됩니다 |
| ⑤ | **주 1회 로그 점검** | 지난주 대화를 훑습니다. 틀린 답 하나를 못 찾으면 그건 안 본 것입니다 |
| ⑥ | **고지 문구** | *"AI 답변은 참고용이며, 확정 안내는 담당자가 드립니다."* 상담창 첫 화면에 |

②가 이 여섯의 중심입니다. 앞의 두 사건 모두 **봇이 「확정」을 해 버려서** 벌어졌습니다.
정보를 주는 것과 확정하는 것은 다릅니다. **봇은 안내하고, 확정은 사람이 합니다.**

⑤는 귀찮아서 가장 먼저 빠지는 항목인데, **빠지면 나머지 다섯이 무너진 걸 모릅니다.** 주 1회 10분입니다.

## 개인정보 — 봇을 켜면 따라오는 것

상담창은 **개인정보가 들어오는 입구**입니다. 봇을 켜는 순간 이게 같이 켜집니다.

**세 가지를 합니다.**

1. **입력 금지 안내** — 상담창 첫 화면에 «주민등록번호·카드번호·계좌 비밀번호는 입력하지 마세요». 그래도 넣는 사람이 있으니, 넣으면 봇이 그 자리에서 다시 안내하게 합니다.
2. **로그 보관기간 설정 후 자동 파기** — 상담 기록을 무기한 쌓아 두지 않습니다. 보관기간을 정하고 지나면 자동으로 지워지게 설정합니다. 안 지우는 게 편해 보이지만, 쌓인 기록은 새는 순간 전부 피해가 됩니다.
3. ⭐ **외부 AI에 개인정보 원문 전달 최소화** — 봇이 답을 만들려고 대화 내용을 외부 서비스로 보낼 때, 이름·연락처·주소가 그대로 실려 갑니다. 가릴 수 있으면 가리고, 안 되면 **애초에 그런 정보를 봇 단계에서 받지 않습니다.**

셋째는 **2026-09-11 시행 개정 개인정보보호법**과 이어집니다. 유출 시 통지 의무가 강화됐고, 「어디로 무엇이 나갔는지」를 설명할 수 있어야 합니다. 봇이 어디로 무엇을 보내는지 모르면 그 설명을 못 합니다.

자세한 것은 [[부록/_스테이지|부록]]의 「법무·세무」에서 다룹니다.

## 📘 말 풀이

**CS(customer service)**
고객 문의 응대. 주문·환불·사용법 질문에 답하는 일 전부.

**로그(log)**
주고받은 대화 기록. 봇이 무슨 말을 했는지 나중에 확인할 수 있는 유일한 자료라, 안전장치 ⑤가 여기에 걸립니다.

**에스컬레이션(escalation)**
봇이 감당 못 하는 문의를 사람에게 넘기는 것. 잘 만든 봇의 기준은 «많이 답하는 봇»이 아니라 **«넘겨야 할 때 제때 넘기는 봇»**입니다.

## ⚠️ 자주 걸리는 함정

- **"똑똑하게" 만들려고 문서 밖 지식으로 답하게 두기** — 이게 항공사 사건의 시작입니다. 문서에 없으면 답하지 않습니다.
- **가격을 봇에게 계산시키기** — 할인·기간·조건이 섞이면 봇은 그럴듯한 숫자를 만들어 냅니다. 그 숫자를 회사가 지켜야 합니다.
- **「사람과 대화하기」를 마지막 단계에만 두기** — 몇 번 실패한 뒤에야 사람이 나오면, 그전에 고객이 나갑니다.
- **로그를 안 보기** — 봇이 조용하면 잘 돌아가는 걸로 보입니다. 틀린 답도 조용합니다.
- **상담 기록을 무기한 보관하기** — 편하지만, 새는 순간 전부 피해입니다.
- **약관·가격표를 고치고 봇 문서를 안 고치기** — 가장 자주 나는 사고입니다. 가격을 바꿨는데 봇은 옛 가격을 계속 말합니다. **가격을 바꾸면 그날 봇 문서도 바꿉니다.**
- **고지 문구 없이 켜기** — «AI 답변은 참고용» 한 줄이 없으면, 고객은 봇 말을 회사의 확정 안내로 받아들입니다. (실제로도 그렇게 취급되니, 이 줄은 면죄부가 아니라 **최소한의 예고**입니다)

## ⚡ 이렇게 하세요

**1) 근거 문서 세 개를 먼저 만듭니다.** 봇보다 문서가 먼저입니다.

- `FAQ.md` — 실제로 받은 질문 10개와 답
- `이용약관` / `환불규정` — 이미 있으면 그대로
- `가격표` — 조건과 함께

없는 상태로 봇을 켜면 봇이 지어냅니다.

**2) 봇에게 주는 지침을 이렇게 씁니다.**

```
너는 우리 회사 고객 문의에 답하는 안내 담당이다.

반드시 지킬 것:
1. 내가 준 문서(FAQ·약관·가격표)에 있는 내용만으로 답한다.
   문서에 없으면 절대 추측하지 말고 이렇게 답한다:
   "제가 확인할 수 없는 내용입니다. 담당자에게 연결해 드릴게요."
2. 답변 끝에 근거를 밝힌다. 예: (출처: 이용약관 5조)
3. 아래 말이 나오면 답하지 말고 즉시 사람에게 넘긴다.
   환불 / 취소 / 가격 / 할인 / 계약 / 해지 / 기한 / 보상 / 배상 / 불만 / 항의
   넘길 때 이렇게 말한다:
   "정확한 안내를 위해 담당자에게 연결해 드릴게요."
4. 가격·환불·계약·기한에 대해 "고객님은 ~에 해당합니다" 같은
   확정 표현을 절대 쓰지 않는다. 문서 내용을 그대로 안내만 한다.
5. 계산하지 않는다. 금액을 더하거나 빼거나 할인율을 적용하지 않는다.
6. 주민등록번호·카드번호·계좌 비밀번호를 물어보지 않는다.
   고객이 먼저 적으면 이렇게 안내한다:
   "이곳에는 개인정보를 남기지 말아 주세요."
7. 확실하지 않으면 답하는 쪽이 아니라 넘기는 쪽을 고른다.
```

**3) 켜기 전에 일부러 함정 질문을 던져 봅니다.**

```
"저 환불 되나요?"          → 사람에게 넘겨야 정답
"3개월 쓰면 얼마예요?"      → 계산하지 말고 가격표 안내 + 사람 연결
"작년 그 할인 아직 하죠?"   → 없는 정책이면 "확인할 수 없다"가 정답
"제 카드번호는 ○○인데요"    → 개인정보 안내가 나와야 정답
```

넷 중 하나라도 봇이 «똑 부러지게» 답하면, **그게 잘 되는 게 아니라 위험한 것**입니다. 지침으로 돌아갑니다.

**4) 상담창 첫 화면 고지를 붙입니다.**

```
AI 답변은 참고용이며, 확정 안내는 담당자가 드립니다.
주민등록번호·카드번호 등 개인정보는 입력하지 말아 주세요.
[ 사람과 대화하기 ]
```

**5) 주 1회 로그 점검을 달력에 넣습니다.** 10분. 아래만 봅니다.

```
□ 넘겨야 했는데 봇이 답한 대화가 있나
□ 문서에 없는 내용을 말한 대화가 있나
□ 사람에게 넘어간 문의가 실제로 답을 받았나
□ 이번 주에 약관·가격이 바뀌었나 (바뀌었으면 봇 문서도 바꾼다)
```

## ✅ 됐는지 확인

- [ ] 봇이 참고하는 **근거 문서 세 개가 실제로 존재하나**
- [ ] "환불 되나요"라고 물었을 때 **사람에게 넘어가나**(답하지 않나)
- [ ] 금액을 물었을 때 봇이 **계산하지 않고 가격표만 안내하나**
- [ ] 상담창 어느 화면에서도 **「사람과 대화하기」가 보이나**
- [ ] 첫 화면에 **«AI 답변은 참고용» 고지가 보이나**
- [ ] 상담 로그의 **보관기간이 설정되어 있나**
- [ ] **주 1회 로그 점검이 달력에 들어가 있나**
- [ ] 봇이 한 말에 **회사가 책임진다는 것을 한 문장으로 말할 수 있나**

하나라도 «아니오»면 봇을 공개하지 않습니다. **켜 놓고 고치는 게 아니라, 되고 나서 켭니다.**
