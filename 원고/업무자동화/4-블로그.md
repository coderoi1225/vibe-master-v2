## 왜 이걸 하나

블로그는 **잠들어 있는 동안에도 새 사람을 데려오는 유일한 채널**입니다.
뉴스레터는 이미 아는 사람에게 가고, 커뮤니티는 이미 들어온 사람이 모이는 곳입니다. 새 사람은 검색으로 옵니다.

그런데 블로그야말로 **자동화 유혹이 가장 큰 곳**이고, 잘못 자동화했을 때 가장 크게 다치는 곳입니다.
"AI로 하루 열 개씩 찍어내면 되지 않나"는 생각이 여기서 나오고, 그 생각이 사이트를 통째로 검색에서 지워 버립니다.

이 절은 **어디까지가 되고 어디부터가 위반인지**를 정확히 그어 놓는 절입니다.

## 자동 발행이 되는 곳은 하나뿐

먼저 현실입니다. 「글이 자동으로 올라가게」 하려면 플랫폼이 그 통로를 열어 줘야 합니다.

| 플랫폼 | 자동 발행 | 실제로 |
|---|---|---|
| **워드프레스** | ⭐ **가능** | 온전히 자동화되는 **유일한 곳**입니다. 발행·수정·태그·예약이 다 됩니다 |
| **티스토리** | ❌ **불가** | 외부에서 글을 올리던 공식 통로가 종료됐습니다 |
| **네이버 블로그** | ❌ 사실상 불가 | 개인이 쓸 수 있는 자동 발행 통로가 열려 있지 않습니다 |

**그래서 선택은 이렇게 갈립니다.**

**추천** — **본인 도메인 + 워드프레스.** 자동화가 되고, 무엇보다 **내 도메인에 글이 쌓입니다.** 플랫폼이 문을 닫아도 글은 내 것으로 남습니다. 뉴스레터에서 산 도메인을 그대로 씁니다.

**대안** — **네이버 블로그를 계속 쓰되 자동 발행을 포기합니다.** 국내 검색 유입이 크게 중요한 업종이면 이쪽이 맞습니다. 대신 이 절의 자동화 중 「발행」만 빼고 나머지(점검·목록 산출)는 그대로 씁니다.

`[확인 필요]` — **네이버 블로그의 공식 API 존재 여부.** 개인이 글을 외부에서 자동 발행할 수 있는 공식 통로가 현재 열려 있는지 확인하지 못했습니다. 네이버 개발자센터에서 직접 확인합니다.

## ⭐ 구글 정책의 정확한 뜻

가장 많이 잘못 알려진 부분입니다. 정확히는 이렇습니다.

> **«AI가 썼는지»는 기준이 아닙니다.**
> 위반은 **순위를 조작할 목적으로, 사용자에게 가치 없는 글을 대량 발행하는 것**입니다.

두 문장을 나란히 놓으면 선이 보입니다.

| 이건 위반이 아니다 | 이건 위반이다 |
|---|---|
| AI로 초안을 쓰고 사람이 고쳐서 발행 | 검색 키워드만 바꿔 가며 비슷한 글을 대량 발행 |
| AI로 자료를 정리해 글을 만듦 | 사람이 한 번도 안 읽은 글을 자동으로 올림 |
| AI로 제목·목차 후보를 뽑음 | 순위를 올리려고 같은 내용을 여러 각도로 복제 |

핵심은 **«AI 글쓰기»가 아니라 «무검수 대량 발행»**이라는 것입니다.
읽는 사람에게 쓸모가 있으면 도구가 무엇이었는지는 문제가 아니고, 쓸모가 없으면 사람이 썼어도 문제입니다.

**1인 회사에 주는 실질적 결론** — AI를 마음껏 쓰되, **발행 전에 사람이 100% 읽습니다.** 그 결과 하루 열 개가 아니라 주 한 개가 되는데, 그게 맞는 속도입니다. 검수 없이 열 개를 올리는 건 앞 절에서 말한 «검토 시간이 절약 시간을 넘는» 상황이 아니라, 아예 **사이트를 걸고 하는 도박**입니다.

`[확인 필요]` — **네이버의 AI 콘텐츠 정책 공식 문서.** 네이버가 AI 생성 글을 어떻게 다루는지에 대한 공식 문서를 확인하지 못했습니다. 네이버 검색 도구(서치어드바이저)의 안내 문서를 직접 확인합니다.

`[확인 필요]` — **AI 기본법의 표시 의무가 개인 블로그 글에도 적용되는지.** 의무를 지는 「이용사업자」의 범위가 아직 모호하고 계도기간 중입니다. 걱정된다면 글 하단에 «이 글은 AI 도움을 받아 작성했습니다» 한 줄을 붙이는 쪽이 안전합니다. 붙여서 잃는 것은 없습니다.

## 색인 요청 — 발행하자마자 자동으로

글을 올려도 검색엔진이 **모르면** 없는 글입니다. 검색엔진이 알아채기까지 며칠에서 몇 주가 걸립니다.

이걸 «내가 방금 글을 올렸다»고 즉시 알리는 방식이 **IndexNow**입니다.
**네이버 검색 도구가 이 방식을 공식 지원합니다.**

- 발행 → 자동으로 색인 요청 발송 → 검색엔진이 빨리 와서 읽어 감
- **사람 손이 전혀 안 갑니다.** 한 번 연결해 두면 끝입니다

이건 이 섹션에서 드문 **순이익 자동화**입니다. 검수할 게 없기 때문입니다. 색인 요청이 잘못 나가도 되돌릴 게 없습니다.

## 발행 «후»의 자동화 — 여기가 진짜 이득

발행 자체보다 이쪽이 1인 회사에 더 남습니다. **전부 검수가 가벼운 일**들입니다.

| 무엇 | 주기 | 결과물 |
|---|---|---|
| **색인 여부 점검** | 주 1회 | "지난주에 올린 3개 중 2개가 아직 색인 안 됨" 목록 |
| **깨진 링크 스캔** | 주 1회 | 404가 난 링크 목록과 그게 있는 글 주소 |
| **6개월 지난 글 목록 산출** | 월 1회 | 오래돼서 내용이 틀렸을 수 있는 글 목록 |

세 가지 모두 **«목록을 내놓는 데서 멈춥니다.»**

> ⭐ **갱신할지는 사람이 판단합니다.**

6개월 지난 글을 자동으로 다시 쓰게 하면, 그건 「무검수 대량 발행」과 같은 자리로 굴러떨어집니다.
자동화는 **"이 글들을 봐야 한다"까지**만 하고, **"이 글을 이렇게 고친다"는 사람이** 합니다.

## 📘 말 풀이

**색인(indexing)**
검색엔진이 내 글을 읽어서 자기 목록에 넣는 것. 색인이 안 되면 아무리 잘 쓴 글도 검색 결과에 나오지 않습니다.

**IndexNow**
"방금 이 주소에 글이 올라왔다"를 검색엔진에 즉시 알려 주는 방식. 검색엔진이 찾아올 때까지 기다리지 않고 내 쪽에서 먼저 알립니다.

**404**
그 주소에 아무것도 없다는 뜻의 오류 번호. 링크를 걸어 둔 상대 페이지가 사라지면 내 글 안의 링크가 404가 됩니다.

## ⚠️ 자주 걸리는 함정

- **"AI가 쓰면 구글이 벌준다"고 믿고 아예 안 쓰기** — 아닙니다. 무검수 대량 발행이 문제입니다. 도구는 마음껏 씁니다.
- **"AI가 쓴 게 아니라고 하면 된다"고 믿기** — 이것도 아닙니다. 감추는 게 아니라 **읽을 만하게 만드는 것**이 기준입니다.
- **티스토리에 자동 발행을 붙이려고 시간 쓰기** — 공식 통로가 종료됐습니다. 되는 길을 찾는 데 며칠을 씁니다.
- **발행 자동화만 켜고 발행 후 점검은 안 하기** — 이득이 더 큰 쪽을 빠뜨리는 겁니다.
- **6개월 지난 글을 자동으로 다시 쓰게 하기** — 목록까지만입니다.
- **키워드만 바꿔 비슷한 글 여러 개 만들기** — 가장 흔한 위반 형태입니다. 한 주제는 한 글로.
- **남의 글을 AI로 «재구성»해서 올리기** — 저작권 문제가 검색 정책 문제보다 먼저 옵니다.

## ⚡ 이렇게 하세요

**1) 발행 자리를 정합니다.** 워드프레스면 자동 발행까지, 네이버 블로그면 발행은 손으로.

**2) 색인 자동 요청을 연결합니다.** (한 번만)

1. 네이버 검색 도구에 사이트를 등록하고 소유 확인을 마칩니다.
2. IndexNow 연동을 켭니다. 워드프레스면 플러그인 하나로 끝납니다.
3. 시험 삼아 글 하나를 발행하고, **색인 요청이 나갔는지** 도구 화면에서 확인합니다.

**3) 발행 전 사람 검수 100%를 규칙으로 못 박습니다.**

```
□ 처음부터 끝까지 읽었다 (훑은 게 아니라 읽었다)
□ 숫자·날짜·이름을 하나씩 확인했다
□ 링크를 전부 클릭했다
□ 이 글을 읽고 독자가 뭘 얻는지 한 문장으로 말할 수 있다
```

마지막 한 줄이 안 나오면 발행하지 않습니다. 그게 「가치 없는 글」의 정의입니다.

**4) 초안을 시킬 때**

```
아래 주제로 블로그 글 초안을 써 줘.

조건:
- 이 글을 읽는 사람이 무엇을 얻는지 첫 문단에서 분명히.
- 내가 준 자료에 없는 사실·숫자·날짜는 절대 만들지 마라.
  필요하면 [확인 필요]로 비워 두고, 무엇을 확인해야 하는지 적어라.
- 검색 키워드를 억지로 반복하지 마라. 사람이 읽는 글로 써라.
- 비슷한 내용을 각도만 바꿔 늘리지 마라. 짧아도 된다.
- 마지막에 "이 글에서 사람이 반드시 확인해야 할 것" 목록을 따로 뽑아 줘.

주제: [여기]
자료: [여기]
```

**5) 발행 후 점검을 예약으로 걸어 둡니다.**

```
매주 월요일에 아래를 확인해서 목록만 만들어 줘. 고치지는 마라.

1. 지난 2주에 발행한 글 중 아직 검색에 색인되지 않은 것
2. 내 사이트 글 안의 링크 중 404가 나는 것 (글 주소와 함께)
3. 발행일이 6개월을 넘긴 글 (제목과 발행일만)

각 목록은 5개를 넘기면 "외 N건"으로 줄여라.
무엇을 고칠지는 제안하지 말고, 목록만 줘. 판단은 내가 한다.
```

## ✅ 됐는지 확인

- [ ] 글을 올릴 자리가 **하나로 정해졌나**(워드프레스인가, 네이버 블로그인가)
- [ ] 글을 발행하면 **색인 요청이 자동으로 나가나**(검색 도구 화면에서 확인)
- [ ] 「발행 전 4줄 점검」이 **적혀 있고, 마지막 글에 실제로 적용했나**
- [ ] 이번 주 점검 결과 **목록이 손에 들어왔나**(색인 안 된 글 / 깨진 링크)
- [ ] 그 목록을 보고 **무엇을 고칠지는 내가 정했나**(자동으로 고쳐지지 않았나)
- [ ] «AI가 썼는지»와 «무검수 대량 발행» 중 **무엇이 위반인지 한 문장으로 말할 수 있나**
