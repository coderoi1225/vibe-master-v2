새 대화를 열 때마다 *"한국어로 답해줘", "이 폴더는 건드리지 마"*를 반복하고 있다면, 어디에도 적어 두지 않은 것입니다. AI는 대화가 끝나면 기억이 남지 않으니, **파일에 적어 둔 것만** 다음 대화로 넘어갑니다.

## ① 두 층을 표로 가른다

「어떻게 일하나」와 「여기가 어떤 곳인가」는 다른 층입니다. 섞어 두면 프로젝트를 옮길 때마다 다시 쓰고, 나눠 두면 한 번만 씁니다.

| | 글로벌 (위층) | 프로젝트 (아래층) |
|---|---|---|
| 어디에 | 홈 폴더 안 설정 폴더 — `~/.claude/CLAUDE.md` | 프로젝트 폴더 맨 위 — `CLAUDE.md` |
| 언제 읽히나 | 모든 프로젝트에서 항상 | 그 폴더에서 일할 때만 |
| 무엇을 적나 | 나와 일하는 방식 | 이 프로젝트의 사실 |
| 예 | 한국어로 답한다 · 결론을 먼저 · 비밀값을 코드에 넣지 않는다 · 지우기 전에 물어본다 | 무엇을 만드나 · 쓰는 도구 · 건드리면 안 되는 폴더 · 자주 쓰는 명령 · 문서가 어디 있나 |

판단은 한 줄입니다 — **다른 프로젝트에서도 참이면 위층, 여기서만 참이면 아래층.** 둘은 자동으로 합쳐져 읽힙니다.

## ② 짧게 쓰고 문서를 가리킨다

지침 파일은 대화를 열 때마다 통째로 읽힙니다. 길면 정작 오늘 할 일을 밀어내므로 **100줄 안**을 목표로 하세요.

길어지는 내용은 문서로 빼고, 지침에는 경로 한 줄만 남깁니다.

```
## ③ 문서 참조
- 요구사항: docs/요구사항.md
- 구조: docs/구조.md
- 결정 기록: docs/결정기록.md
```

이 세 줄이 [[02-명세/_스테이지|Stage 2]]에서 만든 문서를 하네스의 1층으로 끌어올리는 자리입니다. AI는 필요할 때 그 파일을 열어 읽습니다.

## ④ 「실제로 망가진 것」 칸을 둔다

처음 지침을 쓰는 사람은 모범 답안을 적습니다. 모범 답안은 AI의 행동을 바꾸지 않습니다.

| ❌ 의미 없음 | ⭕ 값이 있음 |
|---|---|
| 코드는 깨끗하게 짜자 | 발송 함수를 잘못 짜서 메일이 두 번 갔다 → 보내기 전에 항상 구독 상태를 확인한다 |
| 보안에 신경 쓰자 | 비밀값은 `.env`에만 둔다. 저장 전에 섞였는지 확인한다 |

이 칸은 **사고가 날 때마다 한 줄씩** 늘어납니다. 반 년 뒤에는 같은 실수를 두 번 하지 않게 만드는 가장 비싼 자산이 됩니다. 지금은 제목만 두고 비워 둡니다.

## ⑤ 두 파일을 만들고 새 대화로 시험한다

만드는 것은 아래 ⚡에서 합니다. 중요한 것은 시험 방식입니다 — **대화를 완전히 새로 열고 아무 설명 없이 묻습니다.** 설명한 뒤에 묻는 것은 시험이 아닙니다.

## ⚡ 따라 하기

1. 도구를 열고 아래를 붙여넣어 **글로벌 층**을 만듭니다. 모든 프로젝트에 적용될 「일하는 방식」이므로 홈 폴더에 둡니다. 끝나면 파일 전체 내용이 화면에 보여야 합니다.

```
내 홈 폴더의 ~/.claude/CLAUDE.md 를 열어서(없으면 새로 만들어서) 아래 규칙을 정리해 넣어줘.
- 항상 한국어로 답한다
- 결론을 먼저 말하고, 근거는 그다음에
- 비밀값(키·비밀번호)은 코드나 대화에 절대 넣지 않는다
- 파일을 지우거나 되돌리기 전에 반드시 나에게 먼저 물어본다
- 확인하지 못한 것은 "추측"이라고 표시한다
50줄을 넘기지 말고, 다 쓴 다음 전체 내용을 보여줘.
```

2. Stage 2 문서가 있는 폴더로 옮겨 가서 프로젝트 층을 만듭니다. 이 폴더에서만 참인 사실을 담는 자리이므로 이 폴더에서 실행해야 합니다. 끝나면 `docs/` 경로가 적힌 100줄 안쪽 파일이 보여야 합니다.

```
이 폴더에 맞는 CLAUDE.md를 100줄 이내로 만들어줘. 아래 순서로.
1) 이 프로젝트가 뭔지 3줄
2) 쓰는 도구 목록
3) 반드시 지킬 것 — NEVER / ALWAYS 5개 이내 (진짜 어기면 안 되는 것만)
4) 자주 쓰는 명령
5) 문서 참조 — docs/ 안의 파일들을 경로로 가리키기만 할 것 (내용 복사 금지)
6) 실제로 망가진 것 — 지금은 빈 칸으로 두고 제목만
일반론은 넣지 말고, 이 폴더를 실제로 살펴본 사실만 적어줘.
```

3. `/clear`로 대화를 완전히 새로 엽니다. 방금 대화의 기억이 남아 있으면 지침이 읽힌 건지 알 수 없기 때문입니다. 그리고 아무 설명 없이 아래만 묻습니다.

```
지금 이 프로젝트에서 내가 절대 하면 안 되는 게 뭐야? 그리고 요구사항 문서는 어디 있어?
```

4. 답을 봅니다. 2번에서 적은 NEVER 항목과 `docs/` 경로가 그대로 나오면 두 층이 읽힌 것입니다.

## ✅ 확인

- [ ] 파일이 두 개 생겼나 — 홈 폴더 안 하나, 프로젝트 폴더 안 하나
- [ ] 새 대화에서 설명 없이 3번 질문에 NEVER 항목과 문서 경로가 답으로 왔나
- [ ] 두 파일 모두 100줄 아래이고, 비밀값이 한 글자도 없나

하나라도 «아니오»면 이 절을 다시 봅니다. 여기가 이 장 전체의 바닥입니다.

## 📘 말 풀이

**지침 파일** — AI가 일을 시작할 때 자동으로 먼저 읽는 메모장. 파일 이름이 정해져 있어서(`CLAUDE.md`) 그 이름으로 두면 알아서 읽습니다.

**홈 폴더 (`~`)** — 내 컴퓨터에서 나만의 짐이 놓이는 자리. 앞에 점이 붙은 폴더(`.claude`)는 설정이 놓이는 자리라 평소에 숨겨져 있습니다.

## ⚠️ 함정

**두 층을 섞습니다.** 프로젝트 지침에 "한국어로 답해줘"를 적으면, 프로젝트를 하나 더 만들 때 또 적게 됩니다.

**지침에 비밀값을 적습니다.** 키·비밀번호는 지침 파일에 넣지 않습니다. 지침은 남에게 보여 줄 수 있는 것만 담습니다.

**한 번 쓰고 다시 안 봅니다.** 지침은 살아 있는 문서라, 고치지 않으면 반년 뒤엔 틀린 말이 됩니다. 500줄짜리 지침은 안 읽히는 게 아니라 다른 것을 밀어내면서 읽힙니다.
