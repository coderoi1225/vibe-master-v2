여기까지 문서·지침·훅·스킬을 따로따로 만들었습니다.
**따로 있으면 아무 일도 안 일어납니다.** 한 번 돌려 봐야 내 것이 됩니다.

이 절은 새로 배우는 절이 아니라 **이어서 돌려 보는 절**입니다.
한 바퀴를 돌고 나면 [[05-구현/_스테이지|Stage 5]]의 모든 작업이 이 위에서 돕니다.

## ① 작은 일 하나로 돌려 봅니다

예로 삼는 일 — **「소개 문구를 화면에 넣기」** 정도의 작은 것.
큰 일로 연습하면 어디서 뭐가 걸렸는지 안 보입니다.

| 순서 | 일어나는 일 | 어느 층이 일하나 |
|---|---|---|
| **1** | 대화를 열자 **가지 이름과 바뀐 파일**이 저절로 뜬다 | **훅** (세션 시작) |
| **2** | 설명 없이 시켰는데 **이 프로젝트가 뭔지 이미 안다** | **지침** (1절) |
| **3** | 화면 규칙이 필요하자 **문서를 알아서 열어 읽는다** | **문서** (Stage 2) |
| **4** | 일을 **단계로 쪼갠 목록**을 먼저 보여주고 멈춘다 | **실행 엔진** (2절) |
| **5** | 내가 승인하면 한 단계씩 진행하고 **끝날 때마다 저장**한다 | **실행 엔진** |
| **6** | 손대면 안 되는 폴더를 만지려다 **막힌다** | **훅** (도구 쓰기 직전) |
| **7** | 판단이 필요한 지점에서 **추측하지 않고 물어본다** | **지침 + 실행 엔진** |
| **8** | *"올려도 돼?"라고 했더니 **발행 전 점검이 저절로 펴진다*** | **스킬** (5절) |
| **9** | 자리가 70%를 넘자 **상태를 문서에 적고 비운다** | **컨텍스트 관리** (6절) |
| **10** | 새 대화에서 **"이어서 해줘"** 한 줄로 이어진다 | **문서 + 지침** |

**한 번에 다 되지 않습니다.** 처음 돌리면 대개 4번이나 6번에서 어긋납니다.
어긋난 자리가 곧 **아직 안 채운 층**입니다. 그 절로 돌아가면 됩니다.

## ② 어긋났을 때 어디로 가나

| 이런 증상 | 원인 | 돌아갈 절 |
|---|---|---|
| 새 대화에서 프로젝트를 모른다 | 지침이 없거나 엉뚱한 자리에 있다 | **1절** |
| 지침은 있는데 문서를 안 읽는다 | 지침에 **문서 경로**가 없다 | **1절** |
| 계획 없이 바로 만들기 시작한다 | 실행 엔진 규칙을 안 적었다 | **2절** |
| 막아야 할 것을 그냥 한다 | 지시문에만 적고 훅을 안 걸었다 | **3절** |
| 백업 도구가 아무것도 모른다 | 지침 파일이 이어져 있지 않다 | **4절** |
| 스킬이 안 불려 나온다 | **설명문**에 «언제 쓰나»가 없다 | **5절** |
| 길어지니 앞에서 정한 걸 뒤집는다 | 70%를 넘겼다 | **6절** |

## ⚠️ 여기까지 하면 앞서갑니다 — 실측 근거

저장소를 대량으로 조사한 결과가 있습니다.
**대부분은 지침 파일 하나만 쓰고, 스킬과 서브에이전트는 거의 쓰지 않습니다.**

즉 세상 대부분이 **하네스 2층에서 멈춰 있습니다.**
이 장을 끝까지 한 사람은 1층부터 4층까지 다 채운 것입니다.

이건 재능 차이가 아닙니다. **틀을 짠 사람과 말만 한 사람의 차이**입니다.
그리고 틀은 한 번 짜면 **다음 프로젝트에 그대로 가져갑니다.**

## 📘 말 풀이

**저장 지점**
작업 한 덩어리가 끝났을 때 **지금 상태를 통째로 찍어 두는 것.** 잘못되면 여기로 돌아옵니다. 만드는 법은 [[045-버전관리/_스테이지|Stage 4.5]]에서 제대로 다룹니다. 여기서는 *"단계가 끝나면 찍는다"*만 기억하면 됩니다.

**회고**
한 바퀴가 끝난 뒤 **무엇이 잘됐고 무엇이 걸렸는지 한 줄로 남기는 것.** 이 한 줄이 지침 파일의 「실제로 망가진 것」 칸을 채웁니다.

## ⚠️ 함정

- **큰 일로 첫 바퀴를 돕니다.** 어디서 어긋났는지 안 보입니다. **30분짜리 일**로 돕니다.
- **어긋난 걸 그때그때 말로 때웁니다.** 그러면 다음 바퀴에서 **또** 어긋납니다. 말로 고치지 말고 **층을 고칩니다.**
- **한 바퀴 돌고 끝냅니다.** 두 번째 바퀴가 진짜입니다. 첫 바퀴에서 고친 것이 실제로 먹혔는지는 두 번째에 드러납니다.
- **회고를 안 남깁니다.** 남기지 않으면 반년 뒤 같은 자리에서 같은 실수를 합니다.
- **완벽하게 만들고 시작하려 합니다.** 4층이 다 안 차 있어도 돕니다. **돌리면서 채웁니다.**

## ⚡ 따라 하기

1. **30분짜리 일 하나**를 고릅니다. 그리고 새 대화를 열어 아래를 붙여넣습니다.

```
[작은 일 하나]를 해줘. 아래 순서를 지켜줘.

1) 시작 전에 — 이 프로젝트가 뭔지, 내가 정한 규칙이 뭔지, 관련 문서가 어디 있는지
   네가 아는 대로 먼저 세 줄로 말해줘 (내가 설명하지 않을 거야)
2) 그다음 이 일을 3~5단계로 쪼갠 목록을 보여주고 멈춰. 내 승인을 기다려줘
3) 승인하면 한 단계씩 진행하고, 끝날 때마다 한 줄로 보고하고 저장해줘
4) 오류가 나면 멈추고 보여줘. 판단이 필요하면 추측하지 말고 물어봐
5) 다 끝나면 "올려도 돼?"라고 물을 테니 점검을 돌려줘
```

2. 1번 답이 **틀리면 거기서 멈춥니다.** 지침이 안 읽힌 것입니다 → 1절로.

3. 다 끝나면 **회고 한 줄**을 지침에 넣습니다.

```
방금 작업에서 걸렸던 것 한 가지를 CLAUDE.md의 "실제로 망가진 것"에 한 줄로 추가해줘.
일반론 말고, 방금 실제로 일어난 일로.
```

4. **두 번째 바퀴**를 돕니다. 다른 작은 일 하나로 1~3을 반복합니다.

## ✅ 확인

- [ ] 1번에서 **내가 설명하지 않았는데** 프로젝트를 제대로 말했나
- [ ] **계획 목록이 먼저 나오고 멈췄나**
- [ ] 단계마다 **보고와 저장이 있었나**
- [ ] **훅이 도는 것을 이 바퀴 안에서 봤나** (막힘 또는 시작 화면)
- [ ] **스킬이 저절로 불려 나왔나**
- [ ] 지침 파일에 **회고 한 줄이 늘었나**
- [ ] **두 번째 바퀴**를 돌아 봤나

전부 «예»면 Stage 3은 끝났습니다.
하나라도 «아니오»면 위 표에서 해당 절로 돌아갑니다. **한 절만 다시 보면 됩니다.**
