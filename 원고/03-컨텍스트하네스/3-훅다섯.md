## 왜 이걸 하나

지침에 *"이 폴더는 절대 건드리지 마"*라고 적어 두면 대개 지켜집니다. **대개는.**

2025년, 어느 회사의 AI 에이전트가 **실서비스 데이터베이스를 지웠습니다.**
사후에 밝혀진 것은 기술 결함이 아니었습니다 — *"건드리지 마"*가 **지시문에만 적혀 있었고, 실행 경로에는 아무 강제 장치가 없었습니다.**

> **지시문은 부탁이고, 훅은 잠금장치입니다.**

부탁은 대부분 지켜집니다. 잠금장치는 **항상** 지켜집니다.
남의 돈·남의 개인정보가 걸린 순간부터는 부탁으로는 부족합니다.

## 훅이 걸리는 다섯 자리

훅은 **특정 순간에 자동으로 걸리는 장치**입니다. 걸 수 있는 자리가 정해져 있습니다.

| 언제 | 무엇을 시킬 수 있나 | 비개발자에게 쓸모 |
|---|---|---|
| **도구를 쓰기 직전** | 승인 · **차단** · 고쳐서 실행 | 위험한 명령, 손대면 안 되는 폴더를 **막는다** |
| **도구를 쓴 직후** | 정리 · 검사 · 기록 | 파일을 고칠 때마다 **자동 정리**, 무엇을 고쳤는지 **기록** |
| **알림이 뜰 때** | 다른 곳으로 전달 | 승인 요청을 **휴대폰으로** 받기 |
| **작업이 끝날 때** | 검사하고, 통과 못 하면 되돌리기 | **테스트를 통과 못 하면 「완료」로 안 쳐 준다** |
| **세션이 시작될 때** | 상황을 먼저 보여 주기 | 지금 **어느 가지에 있고 무엇이 바뀌었는지** 첫 화면에 표시 |

가장 값이 큰 둘은 **첫 번째**와 **네 번째**입니다.
첫 번째는 사고를 막고, 네 번째는 *"다 됐습니다"*라는 말을 **검증된 말**로 바꿉니다.

## 실물 — 설정 팩에 이미 들어 있는 것

[[00-환경/2-깔기|Stage 0]]에서 깐 설정 팩에는 훅이 이미 들어 있습니다. 무엇이 도는지 보면 훅이 무엇인지 바로 이해됩니다.

| 언제 | 실제로 하는 일 |
|---|---|
| **세션 시작** | 지금 작업 중인 가지, 바뀐 파일, 하다 만 일을 **첫 화면에 자동 표시** |
| **프롬프트를 넣을 때** | 내가 쓴 말에서 키워드를 잡아 **맞는 스킬을 자동 추천** |
| **파일 편집 후** | 무엇을 고쳤는지 **기록에 남김** |
| **대화를 압축하기 직전** | ★ **대화 내용을 통째로 자동 백업** |

마지막 것이 비개발자에게 바로 값이 됩니다.
대화가 길어져 접을 때(6절), 접히기 **직전에** 원본이 파일로 남습니다.
*"아까 그 얘기 어디 갔지"*가 사라집니다. 내가 아무것도 안 해도 됩니다.

## 잠금장치를 하나 걸어 본다

설정 파일에 이렇게 적으면, **파일을 쓰거나 고치려 할 때마다** 지정한 검사가 먼저 돕니다.

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          { "type": "command", "command": "python3 ~/.claude/scripts/보호폴더-차단.py", "timeout": 5 }
        ]
      }
    ],
    "SessionStart": [
      {
        "matcher": "*",
        "hooks": [
          { "type": "command", "command": "bash ~/.claude/scripts/지금상황.sh", "timeout": 10 }
        ]
      }
    ]
  }
}
```

`matcher`는 **어떤 도구를 쓸 때** 걸지, `command`는 **무엇을 돌릴지**, `timeout`은 **몇 초까지 기다릴지**입니다.
검사가 «막아라»라는 신호를 돌려주면 그 작업은 **일어나지 않습니다.** 설득으로 넘어갈 수 없습니다.

## 📘 말 풀이

**훅(hook)**
**특정 순간에 자동으로 걸리는 장치.** 문에 달린 도어록과 같습니다. 내가 매번 확인하는 게 아니라, 그 순간이 오면 알아서 걸립니다. 설정 파일에 «언제 · 무엇을»만 적어 두면 됩니다.

**도구 호출**
AI가 **파일을 읽고 · 쓰고 · 명령을 실행하는 행동** 하나하나. 말로 답하는 것 말고 실제로 컴퓨터를 만지는 순간입니다. 훅은 대부분 이 순간의 앞뒤에 걸립니다.

**시간 제한(timeout)**
훅이 **몇 초 안에 끝나야 하는지** 정해 두는 숫자. 이 시간이 지나면 훅을 포기하고 넘어갑니다.

## ⚠️ 자주 걸리는 함정

- **⚠️ 시간 제한을 안 겁니다.** 훅이 어딘가에서 멈추면 **전체가 같이 멈춥니다.** 도구가 고장 난 것처럼 보이는데 원인은 내가 건 훅입니다. **모든 훅에 `timeout`을 답니다.**
- **훅을 너무 많이 겁니다.** 매 편집마다 무거운 검사가 돌면 일이 느려져서 결국 훅을 다 끕니다. **차단 하나 + 종료 검사 하나**로 시작합니다.
- **설정 파일에 주석을 답니다.** 이 파일 형식(JSON)에는 **주석을 넣을 수 없습니다.** 넣으면 설정 전체가 무시됩니다.
- **쉼표 하나가 틀립니다.** 괄호와 쉼표가 어긋나면 조용히 안 돕니다. 저장한 뒤 **반드시 실제로 도는지 눈으로 확인**합니다.
- **지침에 적었으니 됐다고 생각합니다.** 이 절의 첫 이야기가 그 결말입니다. **막아야 하는 것은 훅으로 막습니다.**
- **훅 스크립트에 비밀값을 적습니다.** 훅도 결국 파일입니다. 키는 넣지 않습니다.

## ⚡ 이렇게 하세요

1. **지금 무엇이 돌고 있는지** 먼저 봅니다.

```
내 ~/.claude/settings.json 에 지금 어떤 훅이 걸려 있는지 표로 보여줘.
각 줄에 "언제 도는가 / 무엇을 하는가 / 시간 제한이 걸려 있는가"를 적어줘.
시간 제한이 없는 훅이 있으면 표시해줘.
```

2. **잠금장치 하나**를 겁니다. 손대면 안 되는 폴더 이름을 넣습니다.

```
[폴더 이름] 폴더 안의 파일을 쓰거나 고치려 할 때 자동으로 막는 훅을 만들어줘.
- 도구를 쓰기 직전(PreToolUse)에 걸고, Write와 Edit에만 적용
- 막을 때는 왜 막혔는지 한국어로 한 줄 보여줄 것
- timeout은 5초로
- 스크립트는 ~/.claude/scripts/ 에 두고, settings.json에 등록해줘
만든 다음 설정 파일이 형식에 맞는지 검사해서 결과를 보여줘.
```

3. **눈으로 확인합니다.** 새 대화를 열고, 막아 둔 폴더의 파일을 일부러 고쳐 달라고 시킵니다.

```
[막아 둔 폴더]/아무파일.md 에 "테스트"라고 한 줄 추가해줘.
```

→ **막혔다는 메시지가 떠야 성공입니다.** 파일이 고쳐졌으면 훅이 안 걸린 것입니다.

4. 대화를 새로 열어 **첫 화면**을 봅니다. 가지 이름과 바뀐 파일 목록이 저절로 떠 있으면 세션 시작 훅이 도는 것입니다.

## ✅ 됐는지 확인

- [ ] **훅이 실제로 도는 것을 눈으로 봤나** — 막혔다는 메시지가 화면에 떴나
- [ ] 일부러 시킨 편집이 **정말 안 됐나** (파일이 그대로인가)
- [ ] 내가 건 훅 **전부에 시간 제한 숫자**가 붙어 있나
- [ ] 새 대화 첫 화면에 **지금 상황이 저절로** 떠 있나
- [ ] *"막아야 하는 것은 지침이 아니라 훅으로"*를 **한 문장으로 말할 수 있나**

**첫 번째 항목이 «아니오»면 다음 절로 가지 않습니다.** 훅은 도는 것을 봐야 믿을 수 있습니다.
