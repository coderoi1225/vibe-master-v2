지침에 *"이 폴더는 절대 건드리지 마"*라고 적어 두면 대개 지켜집니다 — 대개는. 2025년 어느 회사의 AI 에이전트가 실서비스 데이터베이스를 지웠는데, 원인은 기술 결함이 아니라 그 말이 **지시문에만** 있고 실행 경로에는 강제 장치가 없었던 것입니다.

## ① 다섯 자리를 표로 본다

훅은 특정 순간에 자동으로 걸리는 장치이고, 걸 수 있는 자리가 정해져 있습니다. 부탁은 대부분 지켜지지만 잠금장치는 항상 지켜집니다.

| 언제 | 무엇을 시킬 수 있나 | 비개발자에게 쓸모 |
|---|---|---|
| 도구를 쓰기 직전 | 승인 · 차단 · 고쳐서 실행 | 위험한 명령, 손대면 안 되는 폴더를 막는다 |
| 도구를 쓴 직후 | 정리 · 검사 · 기록 | 파일을 고칠 때마다 자동 정리, 무엇을 고쳤는지 기록 |
| 알림이 뜰 때 | 다른 곳으로 전달 | 승인 요청을 휴대폰으로 받기 |
| 작업이 끝날 때 | 검사하고, 통과 못 하면 되돌리기 | 테스트를 통과 못 하면 「완료」로 안 쳐 준다 |
| 세션이 시작될 때 | 상황을 먼저 보여 주기 | 어느 가지에 있고 무엇이 바뀌었는지 첫 화면에 표시 |

가장 값이 큰 둘은 **첫 번째와 네 번째**입니다. 첫 번째는 사고를 막고, 네 번째는 *"다 됐습니다"*라는 말을 검증된 말로 바꿉니다.

## ② 이미 도는 훅을 확인한다

[[00-환경/2-깔기|Stage 0]]에서 깐 설정 팩에는 훅이 이미 들어 있습니다. 무엇이 도는지 보면 훅이 무엇인지 바로 잡힙니다.

| 언제 | 실제로 하는 일 |
|---|---|
| 세션 시작 | 작업 중인 가지, 바뀐 파일, 하다 만 일을 첫 화면에 자동 표시 |
| 프롬프트를 넣을 때 | 내가 쓴 말에서 키워드를 잡아 맞는 스킬을 자동 추천 |
| 파일 편집 후 | 무엇을 고쳤는지 기록에 남김 |
| 대화를 압축하기 직전 | 대화 내용을 통째로 자동 백업 |

마지막 것이 비개발자에게 바로 값이 됩니다. 대화가 길어져 접을 때(6절) **접히기 직전에** 원본이 파일로 남으므로, *"아까 그 얘기 어디 갔지"*가 사라집니다.

## ③ 잠금장치 하나를 건다

설정 파일에 이렇게 적으면, 파일을 쓰거나 고치려 할 때마다 지정한 검사가 먼저 돕니다.

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          { "type": "command", "command": "python3 ~/.claude/scripts/보호폴더-차단.py", "timeout": 5 }
        ]
      }
    ],
    "SessionStart": [
      {
        "matcher": "*",
        "hooks": [
          { "type": "command", "command": "bash ~/.claude/scripts/지금상황.sh", "timeout": 10 }
        ]
      }
    ]
  }
}
```

`matcher`는 어떤 도구를 쓸 때 걸지, `command`는 무엇을 돌릴지, `timeout`은 몇 초까지 기다릴지입니다. 검사가 «막아라»라는 신호를 돌려주면 그 작업은 **일어나지 않습니다.** 설득으로 넘어갈 수 없습니다.

## ④ 막히는 것을 눈으로 본다

**훅은 도는 것을 봐야 믿을 수 있습니다.** 설정 파일에 적었다고 끝이 아니라, 일부러 막아 둔 일을 시켜서 막히는 메시지를 봐야 이 절이 끝납니다.

## ⚡ 따라 하기

1. 아래를 붙여넣어 지금 걸린 훅부터 봅니다. 새로 걸기 전에 이미 있는 것과 겹치지 않아야 하기 때문입니다. 「언제 / 무엇을 / 시간 제한」 세 칸짜리 표가 보여야 합니다.

```
내 ~/.claude/settings.json 에 지금 어떤 훅이 걸려 있는지 표로 보여줘.
각 줄에 "언제 도는가 / 무엇을 하는가 / 시간 제한이 걸려 있는가"를 적어줘.
시간 제한이 없는 훅이 있으면 표시해줘.
```

2. 손대면 안 되는 폴더 이름을 넣어 잠금장치를 겁니다. 지침에 적은 부탁을 실행 경로의 장치로 바꾸는 것입니다. 끝나면 설정 파일 형식 검사가 «통과»로 보여야 합니다.

```
[폴더 이름] 폴더 안의 파일을 쓰거나 고치려 할 때 자동으로 막는 훅을 만들어줘.
- 도구를 쓰기 직전(PreToolUse)에 걸고, Write와 Edit에만 적용
- 막을 때는 왜 막혔는지 한국어로 한 줄 보여줄 것
- timeout은 5초로
- 스크립트는 ~/.claude/scripts/ 에 두고, settings.json에 등록해줘
만든 다음 설정 파일이 형식에 맞는지 검사해서 결과를 보여줘.
```

3. 새 대화를 열고 막아 둔 폴더의 파일을 일부러 고쳐 달라고 시킵니다. 설정은 새 대화부터 읽히기 때문입니다. **막혔다는 메시지**가 떠야 성공이고, 파일이 고쳐졌으면 훅이 안 걸린 것입니다.

```
[막아 둔 폴더]/아무파일.md 에 "테스트"라고 한 줄 추가해줘.
```

4. 대화를 다시 새로 열어 첫 화면을 봅니다. 가지 이름과 바뀐 파일 목록이 저절로 떠 있으면 세션 시작 훅이 도는 것입니다.

## ✅ 확인

- [ ] 막혔다는 메시지가 화면에 떴고, 파일은 그대로인가
- [ ] 내가 건 훅 전부에 시간 제한 숫자가 붙어 있나
- [ ] 새 대화 첫 화면에 지금 상황이 저절로 떠 있나
- [ ] *"막아야 하는 것은 지침이 아니라 훅으로"*를 한 문장으로 말할 수 있나

첫째가 «아니오»면 다음 절로 가지 않습니다.

## 📘 말 풀이

**훅(hook)** — 특정 순간에 자동으로 걸리는 장치. 문에 달린 도어록처럼 그 순간이 오면 알아서 걸립니다.

**도구 호출** — AI가 파일을 읽고 · 쓰고 · 명령을 실행하는 행동 하나하나. 훅은 대부분 이 순간의 앞뒤에 걸립니다.

**시간 제한(timeout)** — 훅이 몇 초 안에 끝나야 하는지 정해 두는 숫자. 지나면 훅을 포기하고 넘어갑니다.

## ⚠️ 함정

**시간 제한을 안 겁니다.** 훅이 어딘가에서 멈추면 전체가 같이 멈춰서 도구가 고장 난 것처럼 보입니다. 모든 훅에 `timeout`을 답니다.

**훅을 너무 많이 겁니다.** 매 편집마다 무거운 검사가 돌면 느려져서 결국 다 끕니다. 차단 하나 + 종료 검사 하나로 시작합니다.

**설정 파일에 주석이나 쉼표 실수가 들어갑니다.** JSON에는 주석을 넣을 수 없고, 쉼표가 어긋나면 조용히 안 돕니다. 저장한 뒤 반드시 실제로 도는지 눈으로 확인합니다.

**훅 스크립트에 비밀값을 적습니다.** 훅도 결국 파일입니다. 키는 넣지 않습니다.
