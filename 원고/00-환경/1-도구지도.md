시작하는 사람이 가장 많이 잃는 시간은 **도구를 고르는 시간**입니다. 여기서 몇 개를 쓸지 정해 두면 뒤의 모든 장에서 «그건 어느 도구로 하나요»가 사라집니다.

## ① 남아 있는 다섯을 본다

코드를 대신 써 주는 도구는 많았지만, 2026년 9월 기준 실제로 쓰이는 건 다섯입니다. 이름만 알아 두세요.

| 이름 | 한 줄로 |
|---|---|
| **Claude Code** | 대화하면서 파일을 직접 고치고 실행까지 한다. 한국어 공식 문서가 있다 |
| Codex | ChatGPT 쪽 도구. 무료로 들어가는 길이 있고, GitHub에서 코드 검사를 해 준다 |
| Cursor | 편집기 안에 AI가 들어간 형태. 코드를 눈으로 보며 고치는 사람에게 맞는다 |
| Antigravity | 구글 쪽 도구. 무료 |
| Copilot | GitHub에 붙어 있는 도구. 회사에서 이미 쓰고 있다면 이미 손에 있다 |

## ② 둘로 정하는 이유를 본다

하나만 쓰면 그 하나가 멈출 때 내 일도 멈춥니다. 셋 넘게 쓰면 일이 빨라지지 않고 흐름이 끊깁니다 — 어디에 무엇을 시켰는지 내가 못 따라갑니다. 그래서 하루의 대부분을 맡는 메인 하나, 메인이 멈췄을 때 들어가는 백업 하나입니다.

백업이 꼭 필요한 이유는 지난 12개월에 실제로 일어난 일입니다.

- **Windsurf** — 이름이 사라졌습니다.
- **Roo Code** — 문을 닫았습니다.
- **Gemini CLI** — 개인 무료를 끊었습니다.
- **Cursor** — 주인이 바뀌었습니다.

1년 안에 넷입니다. 내가 쓰는 도구가 내년에도 있으리라는 보장은 없으니, 백업은 «혹시»가 아니라 **기본 구성**입니다.

## ③ 내 구성을 고른다

비개발자 한 사람의 현실적인 구성은 이렇습니다.

| 무엇 | 언제 쓰나 | 어디서 |
|---|---|---|
| Claude Code | 계획·만들기·고치기 — 하루의 90% | 데스크톱 앱. 터미널을 안 열어도 됩니다 |
| 앱 안의 코드 리뷰 명령 | 남에게 보이기 전 1차 자체 점검 | 앱 안에서 한 줄 |
| Codex | 커밋(저장) 직전 딱 한 번 | ChatGPT 앱 또는 GitHub |

**대안** — Claude Code 하나로 끝내고, 백업은 무료인 Antigravity로 계정만 만들어 둡니다. 둘로 서로 검사시키는 방식이 얼마나 이득인지는 측정된 적이 없습니다. 하나를 제대로 익히는 게 먼저인 시점이라면 이쪽이 정직합니다.

어느 쪽이든 둘을 동시에 켜 두지 않습니다. 같은 폴더에 두 도구를 동시에 붙이면 같은 파일을 서로 고쳐 충돌이 납니다. 만드는 건 메인 하나, 검사는 마지막에 백업 하나 — 순서대로 씁니다.

## ④ 메인을 열어 첫 말을 건다

**실제로 열어서 답을 받아 봐야 이 절이 끝납니다.** 읽기만 하면 다음 절에서 처음 열게 됩니다.

## ⚡ 따라 하기

1. Claude Code 데스크톱 앱을 내려받아 여세요 — **메인은 이것으로 고정**합니다. 열리면 말을 넣을 수 있는 대화창이 보입니다.
2. 백업 하나를 정하세요 — 이미 ChatGPT를 쓰고 있으면 Codex, 아니면 무료인 Antigravity. 그 사이트에서 계정을 만들고 로그인 화면을 지나면 내 계정 이름이 화면에 보입니다.
3. 백업은 거기서 닫으세요 — 오늘의 목적은 «막혔을 때 열 문이 있다»를 확인하는 것뿐이고, 같이 켜 두면 같은 파일을 두 도구가 덮어씁니다. 닫힌 상태가 정상입니다.
4. 메인 앱에 아래를 붙여넣고 보내세요 — 이 도구가 내 컴퓨터에서 무엇을 할 수 있는지 첫 답으로 확인하기 위해서입니다. 세 줄 설명과 예/아니오 셋이 답으로 돌아오면 됩니다.

```
지금 이 도구가 내 컴퓨터에서 무엇을 할 수 있는지 세 줄로 알려줘.
파일을 읽을 수 있는지, 고칠 수 있는지, 명령을 실행할 수 있는지 각각 예/아니오로.
```

## 📘 말 풀이

**커밋(commit)** — 지금까지 고친 것을 «여기까지 확정» 하고 도장 찍어 저장하는 것. 되돌아올 수 있는 지점이 생깁니다.

**터미널(terminal)** — 글자만 나오는 검은 창. 컴퓨터에 글로 명령하는 곳이고, Claude Code는 데스크톱 앱으로도 쓸 수 있어서 처음에는 안 열어도 됩니다.

## ⚠️ 함정

**«더 좋아 보여서» 갈아탑니다.** 새 도구가 뜰 때마다 옮기면 익숙해질 틈이 없습니다. 메인은 최소한 이 커리큘럼을 끝낼 때까지 바꾸지 않습니다.

**둘 다 유료로 결제합니다.** 이미 ChatGPT를 쓰고 있는 게 아니라면 백업은 무료로 시작합니다. 백업의 역할은 «메인이 멈췄을 때 대피»지 성능이 아닙니다.

**동시에 켜 둡니다.** 같은 폴더를 두 도구가 동시에 만지면 서로 덮어씁니다.
