## 왜 이걸 하나

시작하는 사람이 가장 많이 잃는 시간은 **도구를 고르는 시간**입니다.
새 이름이 뜰 때마다 갈아타면 어느 것도 손에 붙지 않습니다.
여기서 **몇 개를 쓸지** 정해 두지 않으면, 뒤의 모든 장에서 "그건 어느 도구로 하나요"가 반복됩니다.

## 지금 남아 있는 다섯

코드를 대신 써 주는 도구는 많았지만, 2026년 9월 기준 실제로 쓰이는 건 다섯입니다.

| 이름 | 한 줄로 |
|---|---|
| **Claude Code** | 대화하면서 파일을 직접 고치고 실행까지 한다. 한국어 공식 문서가 있다 |
| **Codex** | ChatGPT 쪽 도구. 무료로 들어가는 길이 있고, GitHub에서 코드 검사를 해 준다 |
| **Cursor** | 편집기 안에 AI가 들어간 형태. 코드를 눈으로 보며 고치는 사람에게 맞는다 |
| **Antigravity** | 구글 쪽 도구. 무료 |
| **Copilot** | GitHub에 붙어 있는 도구. 회사에서 이미 쓰고 있다면 이미 손에 있다 |

## 답은 둘이다 — 메인 하나 + 백업 하나

**하나만 쓰면 안 되나요?** — 도구가 하나만 있으면 그 하나가 멈출 때 내 일도 멈춥니다.
**셋 넘게 쓰면 안 되나요?** — 도구를 늘릴수록 일이 빨라지지 않고 **흐름이 끊깁니다.** 어디에 무엇을 시켰는지 내가 못 따라갑니다.

그래서 **둘**입니다. 하루의 대부분을 맡는 메인 하나, 메인이 멈췄을 때 들어가는 백업 하나.

### 백업이 왜 꼭 필요한가 — 지난 12개월 사망 목록

이건 겁주려는 말이 아니라 실제로 일어난 일입니다.

- **Windsurf** — 이름이 사라졌습니다.
- **Roo Code** — 문을 닫았습니다.
- **Gemini CLI** — 개인 무료를 끊었습니다.
- **Cursor** — 주인이 바뀌었습니다.

1년 안에 넷입니다. **내가 쓰는 도구가 내년에도 있으리라는 보장은 없습니다.**
그래서 백업은 "혹시"가 아니라 기본 구성입니다.

## 비개발자 한 사람의 현실적인 구성

| 무엇 | 언제 쓰나 | 어디서 |
|---|---|---|
| **Claude Code** | 계획·만들기·고치기 — **하루의 90%** | 데스크톱 앱. **터미널을 안 열어도 됩니다** |
| 앱 안의 코드 리뷰 명령 | 남에게 보이기 전 1차 자체 점검 | 앱 안에서 한 줄 |
| **Codex** | **커밋(저장) 직전 딱 한 번** | ChatGPT 앱 또는 GitHub |

**대안** — Claude Code 하나로 끝내고, 백업은 **무료인 Antigravity**로 계정만 만들어 둡니다.
둘로 서로 검사시키는 방식이 얼마나 이득인지는 **측정된 적이 없습니다.** 하나를 제대로 익히는 게 먼저인 시점이라면 이쪽이 정직합니다.

### 둘을 동시에 켜 두지 않습니다

같은 폴더에 두 도구를 동시에 붙여 두면 서로 같은 파일을 고쳐 충돌이 납니다.
**순서대로 씁니다** — 만드는 건 메인 하나, 검사는 마지막에 백업 하나. 이게 안전에서도 옳습니다.

## 📘 말 풀이

**커밋(commit)**
지금까지 고친 것을 "여기까지 확정" 하고 도장 찍어 저장하는 것. 되돌아올 수 있는 지점이 생깁니다.

**터미널(terminal)**
글자만 나오는 검은 창. 컴퓨터에 글로 명령하는 곳입니다. Claude Code는 데스크톱 앱으로도 쓸 수 있어서, 처음에는 안 열어도 됩니다.

## ⚠️ 자주 걸리는 함정

- **"더 좋아 보여서" 갈아타기** — 새 도구가 뜰 때마다 옮기면 익숙해질 틈이 없습니다. 메인은 최소한 이 커리큘럼을 끝낼 때까지 바꾸지 않습니다.
- **둘 다 유료로 결제하기** — 이미 ChatGPT를 쓰고 있는 게 아니라면 백업은 무료로 시작합니다. 백업의 역할은 "메인이 멈췄을 때 대피"지 성능이 아닙니다.
- **동시에 켜 두기** — 같은 폴더를 두 도구가 동시에 만지면 서로 덮어씁니다.

## ⚡ 이렇게 하세요

1. 메인을 **Claude Code**로 정하고 데스크톱 앱을 내려받습니다.
2. 백업 하나를 정합니다 — 이미 ChatGPT를 쓰고 있으면 **Codex**, 아니면 무료인 **Antigravity**.
3. 백업은 **계정만 만들어 두고 오늘은 쓰지 않습니다.**
4. 메인 앱을 열고 아래를 그대로 붙여넣어 봅니다.

```
지금 이 도구가 내 컴퓨터에서 무엇을 할 수 있는지 세 줄로 알려줘.
파일을 읽을 수 있는지, 고칠 수 있는지, 명령을 실행할 수 있는지 각각 예/아니오로.
```

## ✅ 됐는지 확인

- [ ] "지금 만드는 건 어느 도구, 검사는 어느 도구"를 **한 문장으로 말할 수 있나**
