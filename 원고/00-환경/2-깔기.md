기본 상태의 AI 도구는 **아무것도 모르는 신입**입니다. 설정을 얹어 두면 매번 설명하지 않아도 같은 방식으로 일합니다.

## ① zip을 통째로 던진다

설치라고 하면 보통 압축을 풀고, 폴더를 찾아 들어가고, 명령어를 칩니다. 그걸 다 건너뛸 수 있습니다. zip 파일을 **압축 풀지 말고 그대로** 대화창에 끌어다 놓고, 아래 문장을 함께 붙여넣으면 됩니다.

```
이 zip 파일에 들어있는 설정을 내 ~/.claude/ 에 적용해줘.
zip 안의 install.sh를 실행하고, 실행 결과를 보여줘.
그 다음 안내에 나오는 플러그인들을 설치해줘.
```

도구가 압축을 풀고, 설치 스크립트를 돌리고, 결과를 보여 줍니다. 내가 할 일은 파일을 던지고 문장을 붙여넣는 것 둘뿐입니다.

이미 설정이 있어도 괜찮습니다. 기존 설정은 자동으로 백업 폴더에 복사된 뒤 새 설정이 들어가고, 문제가 생기면 그 백업 폴더를 되돌리면 원래대로 돌아옵니다.

## ② 설정이 놓이는 두 층을 본다

설정은 두 곳에 나뉘어 놓이고, 둘은 자동으로 합쳐집니다.

| 어디 | 무엇을 적나 |
|---|---|
| **글로벌** (내 컴퓨터 전체) | 일을 어떻게 할 것인가 — 모든 프로젝트에 똑같이 적용 |
| **프로젝트** (그 폴더 안) | 이 프로젝트가 어떻게 돌아가는가 — 이 폴더에서만 적용 |

지금은 자리만 기억해 두세요. 여기에 무엇을 적을지는 [[03-컨텍스트하네스/_스테이지|Stage 3]]에서 채웁니다.

## ③ 네 부품을 구분한다

설정 안에 들어 있는 것은 결국 네 가지입니다.

| 부품 | 무엇인가 |
|---|---|
| 스킬(Skill) | 레시피북. «이 작업은 이런 순서로 해라»를 적어 둔 것. 관련 말이 나오면 알아서 펼쳐집니다 |
| 에이전트(Agent) | 전문가 분신. 따로 떨어져 나가 일하고 결과만 가져옵니다 |
| 슬래시 명령(/명령) | 원클릭 워크플로. 여러 단계를 한 줄로 실행합니다 |
| 훅(Hook) | 자동 실행 장치. 어떤 일이 일어나면(세션 시작, 파일 편집 후 등) 알아서 돕습니다 |

에이전트가 특히 중요합니다. 큰 조사를 메인 대화에서 시키면 결과 더미가 대화창을 가득 채워 정작 중요한 지시가 밀려나지만, 에이전트에게 맡기면 **결론만** 돌아옵니다.

## ④ 단축키 셋을 손에 익힌다

터미널이 무서운 건 대부분 «뭘 눌러야 할지 몰라서»입니다. 이 표면 충분합니다.

| 누르는 것 | 하는 일 |
|---|---|
| `Return` | 줄바꿈 (전송이 아닙니다) |
| `Option` + `Return` | 메시지 보내기 |
| `Esc` | 지금 하는 걸 중단 |
| `Option` + `Up` | 아까 쓴 프롬프트 다시 불러오기 |
| `Option` + `X` | 자동 수락 켜기·끄기 |
| `@` | 파일이나 폴더를 대화에 붙이기 |
| `!` | 명령을 실행하고 그 결과를 붙이기 |
| `#` | 파일 내용을 프롬프트 안에 끼워 넣기 |
| `/compact` | 대화가 길어졌을 때 접어서 자리 만들기 |
| `/cost` | 지금까지 얼마나 썼는지 보기 |

**가장 먼저 익힐 셋** — `Esc`(멈추기) · `@`(파일 붙이기) · `/compact`(자리 만들기).

## ⚡ 따라 하기

1. 앱을 열고 zip 파일을 압축을 풀지 않은 채 대화창에 끌어다 놓으세요 — 도구가 스스로 풀게 하기 위해서입니다. 대화창에 파일 이름이 붙어 보입니다.
2. ①의 설치 문장을 붙여넣고 `Option` + `Return`으로 보내세요 — `Return`은 줄바꿈이라 안 보내집니다. 설치 진행 글이 흘러가고 끝에 **백업 폴더 이름**이 뜹니다.
3. 그 백업 폴더 이름을 메모에 적어 두세요 — 문제가 생기면 되돌릴 자리이기 때문입니다.
4. 아래를 붙여넣어 보내세요 — 설정이 실제로 들어갔는지 숫자로 확인하기 위해서입니다. 네 부품의 개수와 열 개 목록이 답으로 옵니다.

```
지금 내 글로벌 설정에 스킬, 에이전트, 슬래시 명령, 훅이 각각 몇 개 들어 있는지 세어서 알려줘.
그리고 비개발자인 내가 당장 쓸 만한 것 열 개만 골라서 한 줄씩 설명해줘.
```

5. `@` · `Esc` · `/compact`를 한 번씩 눌러 보세요 — 손에 익혀 둘 셋입니다. `@`는 파일 이름 목록이 떠오르고, `Esc`는 답하던 것이 멈추고, `/compact`는 대화를 접었다는 안내가 뜹니다.

## ✅ 확인

- [ ] 설치 결과 메시지에 «백업»이라는 말과 폴더 이름이 보이나
- [ ] 위 프롬프트에 개수(숫자)와 열 개 목록이 답으로 돌아왔나
- [ ] `@`를 눌렀을 때 파일 이름 목록이 떠오르나
- [ ] `Esc`를 눌렀을 때 답하던 것이 멈추나

하나라도 «아니오»면 ⚡의 1로 돌아갑니다.

## 📘 말 풀이

**플러그인(plugin)** — 도구에 나중에 끼워 넣는 추가 기능 묶음. 스킬·에이전트·명령이 한 봉지로 들어옵니다.

**API 키(API key)** — 바깥 서비스를 쓸 때 «나 맞습니다»를 증명하는 긴 글자 줄. 비밀번호와 같아서 설정 파일에만 넣습니다.

## ⚠️ 함정

**압축을 먼저 풀어 버립니다.** 그러면 던지기 방식이 안 됩니다. 풀지 말고 그대로 던집니다.

**API 키를 대화창에 그대로 붙여넣습니다.** 키는 설정 파일에만 넣습니다. 대화 기록에 남으면 안 됩니다.

**`Return`을 눌렀는데 안 보내집니다.** 전송은 `Option` + `Return`입니다. `Return`은 줄바꿈입니다.

**설정 팩에 개발 언어별 스킬이 잔뜩 보여 겁먹습니다.** 안 쓰는 건 그냥 잠들어 있습니다. 있어도 방해하지 않습니다.
