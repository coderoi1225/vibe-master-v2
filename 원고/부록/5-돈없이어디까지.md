무엇이 무료이고, **돈이 드는 지점이 정확히 어디인지.** 금액은 「버전과 값」에 있습니다.

혼자 배우다가 중간에 멈추는 가장 흔한 이유는 어려워서가 아닙니다. **"어? 여기서 돈이 드네"** 하고 멈추는 것입니다.

그런데 대부분의 지점은 **돈을 안 내도 끝까지 갈 수 있습니다.** 어디가 진짜 돈이 드는 자리인지 미리 알면 멈추지 않습니다.

이 절을 안 보면 이렇게 됩니다 — Stage 6에서 결제를 배우려고 결제 대행사에 가입하러 갑니다. **가입비 수십만 원 이야기가 나옵니다.** 팔 사람이 아직 한 명도 없는데 말입니다. 그리고 거기서 멈춥니다.

> **그 돈은 배우는 단계에서 낼 돈이 아닙니다.**

## ① 큰 그림 — 지도 한 장

| 무엇 | 배우는 단계 | 돈이 드는 지점 |
|---|---|---|
| AI 코딩 도구 | **하나는 무료 진입로가 있습니다** | 매일 쓰기 시작하면 한도가 찹니다 → **첫 유료 지출** |
| 코드 저장소 | ✅ 무료 | 비공개 저장소에서 자동 검사를 많이 돌릴 때 |
| 배포 | ✅ 무료 | 방문자가 많아질 때 · 팀으로 쓸 때 |
| 데이터베이스 | ✅ 무료 | 용량이 차거나, **쉬면 멈추는 것이 불편해질 때** |
| 도메인(내 주소) | ❌ **처음부터 돈이 듭니다** | 연 단위 결제. 액수는 작습니다 |
| 이메일 발송 | ✅ 무료 구간 있음 | 구독자가 늘 때. **단 발신 도메인이 먼저 필요** |
| 에러 추적 | ✅ 무료 | **여기가 대개 가장 먼저 찹니다** |
| 디자인 도구 | ✅ 무료로 상당히 됩니다 | 브랜드 자동 적용 · 협업 기능 |
| **결제 대행 계약** | ⛔ **배우는 단계에서는 안 합니다** | **팔 사람이 생겼을 때** |
| 세무 대행 | ⛔ 아직 | 매출이 생긴 뒤 |
| 법률 검토 | ⛔ 아직 | **돈을 받기 직전에 한 번** |

**정리하면 배우는 단계에서 실제로 나가는 돈은 셋입니다.**

1. **도메인** — 작습니다. 그리고 이게 없으면 뉴스레터 발송 인증이 아예 안 됩니다.
2. **AI 도구 사용료** — 매일 쓰면 무료 한도가 찹니다. **여기가 첫 번째 진짜 지출입니다.**
3. **(선택) 법률 검토 한 번** — 돈을 실제로 받기 직전에.

**나머지는 전부 미룰 수 있습니다.**

## ② 결제 — 테스트 모드까지만

가장 크게 오해하는 자리입니다.

> **결제를 "배우는 것"과 결제를 "받는 것"은 완전히 다른 일입니다.**

| | 테스트 모드 | 실제 계약 |
|---|---|---|
| 필요한 것 | **가입만.** 대개 사업자 등록도 필요 없습니다 | 사업자등록증 · 심사 · 계약 |
| 돈 | **0원** | 가입비 · 연회비 · 수수료 |
| 되는 것 | 결제 창 띄우기 · 성공/실패 흐름 · 웹훅 받기 · 정기결제 흐름 · 해지 흐름 | 진짜 돈이 들어옵니다 |
| 언제 하나 | **Stage 6 학습 내내** | **첫 손님이 생겼을 때** |

**테스트 모드로 어디까지 만들 수 있나** — 배우는 데 필요한 것은 사실상 전부입니다.

- 결제 창을 띄우고 성공·실패를 다르게 처리하기
- 결제 완료 웹훅을 받아 내 데이터베이스에 기록하기
- 웹훅이 두 번 왔을 때 중복을 막기
- 정기결제(빌링) 등록과 다음 달 자동 청구 흐름
- **해지 화면 만들기** — 다크패턴 규제 때문에 이게 실제로 중요합니다
- 실패했을 때 재시도와 알림

> **[확인 필요]** — 테스트 모드에서 정확히 어디까지 되는지는 **대행사마다 다릅니다.** 특히 정기결제와 일부 간편결제는 테스트 지원 범위가 갈립니다. 가입 전에 각 사의 개발자 문서를 확인하고, 결과를 「버전과 값」 표 ④에 적어 두세요.

### 그럼 실제 계약은 언제 하나

**이 셋이 다 되면 그때입니다.**

1. 서비스가 **남의 기기에서 실제로 열린다**.
2. **돈을 내겠다고 말한 사람이 한 명 이상** 있다.
3. **법무 부록의 준비물이 끝났다** — 사업자 등록 · 처리방침 · 해지 동선 · 푸터 표기.

셋 중 하나라도 안 됐으면 계약하지 않습니다. **계약을 먼저 하면 준비되기 전에 돈이 나갑니다.**

## ③ 무료 한계는 대개 어디서 먼저 걸리나

**순서가 있습니다.** 이 순서를 알면 놀라지 않습니다.

| 순서 | 어디 | 왜 여기가 먼저인가 | 걸리면 어떻게 되나 |
|---|---|---|---|
| **1** | **AI 도구 사용 한도** | 매일 쓰면 가장 빨리 찹니다 | 작업이 멈춥니다. **그래서 백업 도구가 하나 필요합니다** |
| **2** | **에러 추적 건수** | 에러 하나가 여러 건으로 쌓입니다. **버그 하나가 한 달 한도를 다 먹기도** 합니다 | 그 뒤의 에러가 안 보입니다. **가장 위험한 종류의 한도 초과** |
| **3** | 비공개 저장소의 자동 검사 시간 | 커밋마다 검사가 돌면 빨리 찹니다 | 검사가 안 돌아 PR이 멈춥니다 |
| **4** | 이메일 발송 건수 | 구독자 수 × 발송 횟수 | 발송이 막힙니다 |
| **5** | 데이터베이스 — 쉬면 멈춤 | 며칠 안 쓰면 잠들 수 있습니다 | 첫 접속이 느리거나 실패합니다. **남에게 보여줄 때 하필 이럽니다** |
| **6** | 배포 대역폭 | 방문자가 늘어야 걸립니다 | 대개 한참 뒤입니다 |

> **2번이 왜 위험한가** — 에러 추적 한도를 넘으면 **그 뒤의 에러가 기록되지 않습니다.** 그런데 화면에는 아무 표시가 없습니다. *"에러가 없네"*가 아니라 *"안 보이는 것"*입니다. 무료 한도 알림을 반드시 켜 두세요.

**숫자는 「버전과 값」 표 ③에 있습니다.** 확인 날짜와 함께요.

## ④ 순서 — 무엇에 먼저 돈을 내나

돈이 생겼을 때 순서입니다.

| 순위 | 무엇 | 왜 이 순서인가 |
|---|---|---|
| 1 | **도메인** | 뉴스레터 발신 인증의 전제입니다. 없으면 메일이 아예 거부됩니다. 액수도 가장 작습니다 |
| 2 | **AI 도구 하나** | 매일 쓰는 도구입니다. 여기서 멈추면 다 멈춥니다 |
| 3 | **에러 추적 한 단계 위** | 안 보이는 에러가 가장 비쌉니다 |
| 4 | **법률 검토 한 번** | 돈을 받기 직전에. 물어볼 것을 정리해 가면 짧게 끝납니다 |
| 5 | **결제 대행 계약** | 팔 사람이 생겼을 때 |
| 6 | 세무 대행 | 매출이 생기고 신고가 부담스러워질 때 |
| 7 | 디자인 도구 유료 · 두 번째 AI 도구 | **가장 나중.** 없어도 됩니다 |

> **두 번째 AI 도구가 왜 마지막인가** — 교차 리뷰가 **얼마나 이득인지는 측정된 적이 없습니다.** 그리고 이미 다른 AI 구독이 있다면 추가 비용이 0이라 계산이 달라집니다. **없으면 하나를 제대로 익히는 것이 먼저입니다.**

## ⑤ 배우는 단계에서 안 사도 되는 것

| 무엇 | 왜 아직인가 |
|---|---|
| 결제 대행 계약 | 테스트 모드로 다 배웁니다 |
| 유료 감시·모니터링 서비스 | 무료로 충분합니다. ⚠️ **단 개인·비상업 한정 무료 서비스를 파는 서비스에 쓰면 약관 위반**입니다 |
| 유료 이메일 플랜 | 구독자가 생긴 뒤 |
| 디자인 도구 유료 플랜 | 무료로도 **템플릿을 고정하고 글자만 바꾸는 방식**이면 일관성이 잡힙니다 |
| 유료 이미지·영상 생성 서비스 | 편집 중심으로 우회할 수 있습니다 (Stage 4) |
| 유료 강의 | 이 커리큘럼과 공식 문서로 갑니다 |
| 서버를 직접 빌리기 | 배포 서비스 무료 구간이 훨씬 쉽고 안전합니다 |

## 📘 말 풀이

**테스트 모드**
결제 대행사가 주는 **가짜 결제 환경.** 진짜 카드도 진짜 돈도 오가지 않지만 결제 흐름은 똑같이 돕니다. 여기서 만든 코드는 나중에 **키만 바꾸면** 실제로 동작합니다.

**무료 한도(free tier)**
"여기까지는 공짜"의 경계선. 대개 **월 단위로 초기화**되고, 넘으면 **막히거나 요금이 붙습니다.** 어느 쪽인지는 서비스마다 다르니 미리 확인하세요.

**발신 도메인**
내 메일이 **진짜 나에게서 왔다는 것을 증명하는 주소.** 남의 무료 메일 주소로는 이 증명을 할 수 없어서, 뉴스레터를 보내려면 내 도메인이 반드시 필요합니다.

## ⚠️ 함정

| 함정 | 무슨 일이 생기나 |
|---|---|
| **배우려고 결제 대행 계약부터 함** | 팔 사람이 없는데 가입비가 나갑니다. **테스트 모드면 됩니다** |
| **무료 한도 알림을 안 켬** | 특히 에러 추적이 조용히 막힙니다. **에러가 없는 게 아니라 안 보이는 것** |
| **AI API에 사용량 상한을 안 검** | 워크플로가 고리에 빠지면 **하룻밤에 크게 나갑니다.** 상한을 먼저 겁니다 |
| **개인 카드로 서비스 요금 결제** | 나중에 사업 비용으로 정리하기 어려워집니다 |
| **개인·비상업 한정 무료 서비스를 파는 서비스에** | 약관 위반입니다. 무료라고 다 쓸 수 있는 게 아닙니다 |
| **무료라서 다 켜 둠** | 안 쓰는 서비스가 늘면 **처리방침에 적을 국외이전 항목만** 늘어납니다 |
| **도메인을 마지막에 삼** | 뉴스레터를 만들어 놓고 보낼 수가 없습니다. **가장 먼저 사세요** |

## ⚡ 따라 하기

### 첫날 — 0원으로 세팅하는 순서 (60분)

1. 코드 저장소 계정을 만든다. **무료.**
2. 배포 서비스에 저장소를 연결한다. **무료.**
3. 데이터베이스 프로젝트를 하나 만든다. **무료.** 가능하면 **서울 리전**을 고릅니다(「법무·세무」의 국외이전이 가벼워집니다).
4. 에러 추적을 붙이고 **무료 한도 알림을 켠다.** 이 단계를 건너뛰지 마세요.
5. AI 코딩 도구 하나를 무료 진입로로 시작한다.
6. **여기까지 0원입니다.**

### 돈 쓰기 전에 스스로에게 묻는 셋

```
1) 지금 이걸 안 사면 오늘 무엇이 막히나?
   → "막히는 게 없다"면 아직입니다.

2) 무료 한도의 어느 줄에서 걸렸나?
   → 모르면 아직 안 걸린 것입니다.

3) 돈을 내겠다고 말한 사람이 있나?
   → 결제 대행 계약은 이 답이 "예"일 때만 합니다.
```

### 상한 걸기 — 오늘 30분

돈이 새는 자리는 셋입니다. **셋 다 상한이나 알림을 걸 수 있습니다.**

| 어디 | 무엇을 거나 |
|---|---|
| AI API | **월 사용량 상한.** 넘으면 아예 멈추게 |
| 자동화 워크플로 | **실행 횟수 상한.** 고리에 빠져도 폭주하지 않게 |
| 무료 한도 있는 서비스 전부 | **한도 도달 알림.** 특히 에러 추적 |

### 유료로 넘어갈 때 — 카드부터 바꾼다

첫 유료 결제를 하기 전에 **사업용 카드**를 먼저 만듭니다. 개인 카드로 시작하면 나중에 전부 옮겨야 하고, 그 사이의 비용은 정리하기 어려워집니다. (「법무·세무」 ⑧)

- [ ] 「버전과 값」 표 ③의 무료 한도 칸이 **채워져 있나?**

## 🔎 더 깊이

**어디서 확인하나**

무료 한도의 실제 숫자는 **각 서비스의 공식 요금 페이지**에서만 확인합니다. 그리고 그 값은 **「버전과 값」 표 ③**에 확인 날짜와 함께 적어 둡니다. 이 절은 *"어디서 먼저 걸리는가"*만 다루고 숫자를 갖지 않습니다.

**무엇을 검색하면 되나**

`free tier limits` · `usage limits` · `spend limit` · 각 서비스의 `pricing` 페이지 안의 **"무료 플랜에 포함되지 않는 것"** 목록. 대개 이 목록이 진짜 정보입니다.

**이어지는 곳**

- 결제 테스트 모드 실습 → **Stage 6**
- 무료 자동화 실행 시간 → **Stage 7**
- 무료 감시·알림 구성 → **Stage 8**
- 사업자 등록과 세금 순서 → 부록 **「법무·세무」**
- 실제 금액과 확인 날짜 → 부록 **「버전과 값」**
