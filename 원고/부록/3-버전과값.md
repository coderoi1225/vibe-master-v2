## ③ 새 값이 생기면 여기에 넣는다

본문을 쓰다가 요금·버전·모델 이름을 쓰고 싶어지면, 본문에는 이렇게만 씁니다.

```
요금과 버전은 부록 「버전과 값」에서 확인 날짜와 함께 관리합니다.
```

그리고 **이 절의 알맞은 표에 줄을 하나 추가**합니다. 표가 없으면 `무엇` / `값` / `확인한 날짜` / `어디서 확인` 네 칸으로 새 표를 만듭니다. 본문에는 숫자를 남기지 않습니다.

## ⚡ 따라 하기

값 하나를 확인할 때와, 분기마다 전체를 갱신할 때 같은 순서입니다.

1. 표에서 찾은 줄의 **「확인한 날짜」를 먼저 읽으세요.** 값보다 날짜가 먼저입니다 — 3개월이 넘었으면 그 값을 믿지 말고 다음 단계로 갑니다. 3개월 안이면 그대로 씁니다.
2. 그 줄의 **「어디서 확인」에 적힌 공식 페이지를 여세요.** 검색하면 블로그가 먼저 나오기 때문에 적어 둔 주소로 바로 갑니다. 제조사가 직접 운영하는 주소인지 화면에서 확인합니다.
3. 페이지를 직접 열기 어려우면 AI에게 아래를 붙여 **페이지의 글자만 옮겨 적게 하세요.** 페이지를 열지 않고 대답한 답은 버립니다. 통화 단위·과금 주기·오늘 날짜가 함께 적힌 답이 와야 합니다.

```
아래 주소를 열어서 지금 화면에 적힌 요금제 이름과 금액만 그대로 옮겨 적어 줘.
[공식 요금 페이지 주소]

규칙:
- 네 기억으로 채우지 마. 페이지에 없으면 "페이지에 없음"이라고 써.
- 통화 단위와 과금 주기(월/연)를 같이 적어.
- 오늘 날짜를 함께 적어.
```

4. 값이 같으면 **날짜만 오늘로** 바꾸세요. 값이 달라졌으면 값과 날짜를 함께 바꾸고, 🔎의 «이 절을 쓰는 다른 절들»에서 그 값을 쓰는 절을 찾아 같이 봅니다.
5. 못 찾았으면 **`[확인 필요]`로 되돌리세요.** 옛 값을 그대로 두면 날짜만 낡은 채 남아 다음 사람이 믿게 됩니다.
6. 분기 갱신(1·4·7·10월 첫 주)에는 표를 위에서부터 훑어 **3개월 넘은 줄에 표시한 뒤** 1~5를 줄마다 반복하세요. 30분이면 끝납니다.

## 📘 말 풀이

**리전(region)** — 서비스의 데이터가 실제로 놓인 **지역**. 서울 리전을 고르면 데이터가 국내에 저장되고, [[부록/1-법무세무|법무·세무]]의 국외이전 문제가 가벼워집니다.

**MoR (Merchant of Record)** — "판매자를 대신 맡아 주는 회사". 이 회사가 형식상 판매자가 되어 세금과 결제를 처리해 줍니다. 해외 결제 서비스를 직접 못 쓸 때 쓰는 우회로입니다.

**테스트 모드** — 결제 대행사가 주는 **가짜 결제 환경.** 실제 카드도 실제 돈도 쓰지 않고 결제 흐름을 끝까지 만들어 볼 수 있습니다.
