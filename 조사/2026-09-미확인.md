# 왜 아직 [확인 필요]인가

> **왜 이 파일이 있나** — 다음 사람(석 달 뒤의 형석님 포함)이 **같은 헛수고를 반복하지 않게** 하기 위해서입니다.
> 「못 찾았다」와 「찾을 수 없다」는 다릅니다.

## 이유별로

### ① 가입해야 보이는 값 — 찾아도 안 나옵니다

간편결제 수수료율 · 테스트 모드로 어디까지 되는지 · 이미지 편집 도구 요금제.

**공개 페이지에 없고 계약·가입 후에 안내됩니다.** 검색으로 나오는 숫자는 대부분 블로그 재인용이라 믿을 수 없습니다.

> **다시 볼 시점** — 실제로 가입할 때. 그때 화면에 뜨는 값을 부록에 옮겨 적으면 됩니다.

### ② 집행 강도 — 조문은 있는데 사례가 없습니다

접근성 법의 실제 집행 · 개인사업자 단독 사이트 적용 여부 · AI 기본법의 「이용사업자」 범위.

**조문은 확인했지만 「그래서 실제로 어떻게 되나」는 판례나 처분 사례가 필요합니다.**

> **다시 볼 시점** — 첫 처분 사례가 나올 때. 그전까지는 **보수적으로**(적용 대상이라고 보고) 가는 것이 맞습니다.

### ③ 원문 대조 실패 — 2차 출처만 있습니다

수신동의 2년 재확인 조문 · 네이버 블로그 공식 API 존재 여부 · 네이버 AI 콘텐츠 정책 공식 문서.

**여러 곳에서 같은 말을 하는데 1차 출처를 못 찾았습니다.** 남들이 다 그렇게 말한다는 것은 근거가 아닙니다.

### ④ 자기 기기에서 재야 하는 것

노트북을 **덮었을 때** 예약이 도는지.

**기기와 절전 설정마다 달라 일반화할 수 없습니다.** 원고에 확인 명령(`pmset -g`)을 넣어 각자 재게 했습니다.

### ⑤ 이번에 안 쓰기로 한 것

시크릿 스캔 무료 대체 도구 · 국내 메일 발송 서비스 요금 · 사이트 감시 도구 요금.

**도구 이름만 적고 요금은 비웠습니다.** 실제로 쓸 때 확인하는 편이 낫습니다 — 지금 적어도 그때는 낡아 있습니다.
