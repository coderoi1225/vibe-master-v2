# 실측 아홉 — 무엇을 어떻게 쟀고 무엇이 나왔나

> **왜 이 파일이 있나** — 원고에는 결론만 있습니다. 여기에는 **어떻게 쟀는지**가 있습니다.
> 석 달 뒤 "이게 아직도 맞나" 물을 때, 같은 방법으로 다시 재려면 이 파일이 필요합니다.
>
> **아홉 중 여덟이 원고를 바꿨습니다.** 돌려 보지 않았으면 틀린 채로 남았을 것들입니다.

## ① · ⑨ 피그마 — 변수는 되고 Code Connect는 안 된다

**어떻게 쟀나**
1. 계정 정보를 물었다 → `Pro 팀 · Full 시트` · 팀 하나
2. 빈 파일을 만들고 **변수 7개**를 넣었다 — 색 3(주색·강조·글자) · 간격 4(안 4 · 사이 8 · 구역 24 · 큰 32)
3. 그 변수에 묶은 히어로 화면 하나를 만들고 **코드로 다시 받았다**
4. Code Connect 매핑을 불러 봤다

**나온 것**
```
background: var(--색/주색, #1f7a5c)
gap:        var(--간격/구역, 24px)
```
- **한글 변수 이름이 그대로 코드에 나온다.** 값을 손으로 안 적어도 이름이 따라온다.
- ⚠️ **변수로 묶은 것만 변수로 나온다.** 글자 색은 안 묶었더니 `text-white`로 박혀 나왔다.
- ❌ **Code Connect 거절** — *"Organization 또는 Enterprise 플랜의 Dev 또는 Full 시트가 필요합니다."*
  **시트는 되는데 플랜 등급이 모자라다.** `[확인 필요]`였던 것을 **불가로 확정.**

**원고 반영** — Stage 4 3절(규칙표) · 10절(도구 순서). Code Connect 자리를 **변수(규칙표)** 로 대체.

## ② 캔바 — 무료 플랜에서 한글이 안 들어간다

**어떻게 쟀나**
1. 브랜드 킷 목록을 불렀다 → **0개** (무료 플랜, 형석님 확인)
2. 인스타그램 게시물로 카드뉴스 첫 장을 **AI에게 만들게 했다** — 요청 문구: *"디자인은 감각이 아니라 숫자다"*
3. 만들어진 장을 복제하고 **글자만 한글로 교체**했다

**나온 것**
- ✅ **1080×1350** (4:5) 확인. 원고의 숫자가 맞다.
- ❌ **AI가 한글을 못 넣는다.** 실제로 들어간 글자 — **「매일 보는날」, 「콘텐츠서」.** 뜻이 없는 조각.
- ⚠️ 글자 교체는 **내용은 정확히 들어갔지만**, 글상자 폭이 고정이라 「디자인은」이 「디자 / 인은」으로 쪼개져 아래 글자와 겹쳤다.
- 배경이 **단색이 아니라 이미지**로 들어온다. 색만 바꾸려 해도 배경을 통째로 갈아야 한다.

**원고 반영** — Stage 4 8절(카드뉴스). **「원본 템플릿의 글자 수를 세어 두고 그 안에서 쓴다」** 규칙 추가.

## ③ starter 저장소 — 결제도 로그인도 없다

**어떻게 쟀나** — `coderoi1225/vibe-master-newsletter-starter`(공개)를 클론해 파일 25개를 전부 열었다.

**원고 반영** — Stage 6 2절. **「완성된 예제」가 아니라 「출발점」**으로 고쳐 적음.

## ④ PR 한 바퀴 — 무료 비공개로는 문을 못 잠근다

**어떻게 쟀나** — 가지를 내고 검사 파일을 넣어 PR을 열고, 브랜치 보호를 켜려 했다. 그다음 **일부러 코드블록을 안 닫고** 올려 검사가 잡는지 봤다.

**나온 것**
- ⚠️ **첫 검사가 0초 만에 실패하고 로그도 안 남았다.** 원인 — **작업 아이디에 한글**을 씀. GitHub Actions는 job id에 영문·숫자·`-`·`_`만 받는다. `verify:` + `name: 검사`로 고치니 **7초에 통과.**
- ❌ **브랜치 보호 거절** — *"GitHub Pro로 올리거나, 이 저장소를 공개로 바꾸세요."* 규칙집(ruleset)도 **똑같이 거절.**
  → **무료 계정 + 비공개 저장소에서는 검사 통과를 강제할 수 없다.**
- ✅ 일부러 깨뜨리니 **「코드블록 짝이 맞나」에서 정확히 걸렸다.** 되돌리니 통과.
- → 저장소를 **공개로 전환**한 뒤 브랜치 보호가 켜졌고, `main`에 직접 밀어 보니 막혔다:
  `! [remote rejected] main -> main (protected branch hook declined)`
- ⚠️ 공개 전환 시 **push 보호가 자동으로 켜져** 교재 안의 **가짜 열쇠 예시까지 막았다.** 모양만 맞으면 걸린다.

**원고 반영** — Stage 7 2절 · 3절. 「공개/비공개가 무료 범위를 가르는 선」으로 묶어 적음.

## ⑤ 되돌리기 4단 — revert는 커밋이 늘어난다

**어떻게 쟀나** — 연습용 저장소를 따로 만들어 일부러 망가뜨리고 네 가지로 되살렸다. **본 저장소는 건드리지 않았다.**

| 상황 | 한 일 | 결과 |
|---|---|---|
| 아직 커밋 안 함 | `restore` | 원래 내용으로 돌아옴 |
| 커밋했는데 안 밀었음 | `reset` | 커밋 3 → 2, 파일도 돌아옴 |
| 이미 밀었음 | `revert` | **커밋 3 → 4로 «늘었다».** 지우지 않고 되돌리는 커밋이 쌓인다 |
| 날린 것 같을 때 | `reflog` | **날린 커밋이 목록에 그대로 있었고** 번호로 되살렸다 |

**원고 반영** — Stage 4.5 5절. 세 번째가 가장 헷갈리는 자리라 그대로 적음.

## ⑦ 터미널 · 잠자기 — 창을 닫아도 산다

**어떻게 쟀나**
1. `tmux` 세션에 **1초에 한 줄씩 기록하는 긴 작업**을 걸고 3초 뒤 확인 → **3줄**
2. 그 셸을 **완전히 끝냈다**
3. 새 셸에서 다시 붙었다 → **11줄**
4. `pmset -g`로 잠자기 설정을 봤다

**나온 것**
- ✅ `tmux 3.7b` 설치돼 있음. **셸을 끝내도 작업이 계속 돌았다.**
- 이 컴퓨터(맥미니 M4 Pro 24GB): `sleep 0`(**절대 안 잠듦**) · `displaysleep 5`(**화면만** 꺼짐) · `autorestart 1`(**정전 뒤 자동 재시작**) · `uptime` **9일 11시간**
- → **「덮었을 때」 질문 자체가 반쯤 틀렸다.** 덮개 없는 데스크톱에서는 **잠자기 설정**이 답을 가른다.

**원고 반영** — Stage 0 5절 · Stage 8 1절. **노트북/데스크톱 두 길**로 나눠 다시 씀. 확인 명령을 본문에.

## ⑧ 코덱스 교차 리뷰 — 진짜 버그 셋을 찾았다

**어떻게 쟀나** — `@openai/codex` 0.154.0 설치(형석님 승인, ChatGPT 구독 있음). 읽기 전용으로 걸고 **`발행/build.py`(400줄)** 를 리뷰시켰다. 프롬프트 — *"진짜 문제만 심각한 순서로 5개까지, 칭찬은 쓰지 마."*

**나온 것 — 다섯 중 셋이 진짜였다**

| 지적 | 확인 | 조치 |
|---|---|---|
| 한글 주소가 인코딩돼 돌아와 일부 장이 목차로 튕김 | ✅ **진짜** | 고침 |
| 복사 버튼 글자가 복사한 코드에 섞임 | ✅ **진짜** | 고침 |
| 제목 기본값이 앞 반복문의 변수를 가리킴 | ✅ **진짜** | 고침 |
| 절 번호가 겹치면 읽음 표시가 섞임 | 드문 경우 | 고침 |
| 원고의 HTML이 그대로 실행됨 | 사실 | **안 고침** — 내가 쓴 글을 내가 굽는 구조, 막으면 절 사이 링크까지 지워짐 |

**가장 큰 것** — 「부록」과 「업무 자동화」를 누르면 **전체 목차로 튕겼다.** 주소창이 한글을 `%EB%B6%80...`로 바꿔 돌려주는데 코드가 원래 글자와 비교하고 있었다. **열네 장 중 두 장이 안 열리는데 원고를 읽어서는 못 찾는다.**

**덤** — 같은 컴퓨터에서 두 도구의 설정 폴더를 열어 보니: 쓰던 쪽은 지침이 여러 층·스킬 9개, **새로 깐 쪽은 지침 0줄·스킬 0개.** Stage 3의 「서로 안 읽는다」가 주장에서 실측으로 바뀜.

**원고 반영** — Stage 7 4절 · Stage 3 4절. **「흔하지만 효과가 측정된 적은 없다」**는 문장은 그대로 유지 — 이번 한 번의 사례가 효과 측정은 아니다.
